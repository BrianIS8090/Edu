# Промпты для инженерных задач — как правильно спрашивать LLM

«ChatGPT мне дал какой-то бред» — частая жалоба инженеров, которые попробовали LLM и разочаровались. На самом деле бред дали не ChatGPT, а сам промпт. LLM — это собеседник, который не знает вашего контекста: ни проекта, ни стандартов 7Lamp, ни целей. Чем точнее и полнее вы сформулируете запрос, тем полезнее будет ответ. В этом уроке — практические шаблоны промптов для типовых задач инженера. Парный урок — [Как LLM усиливает инженера](lessons/онбординг-инструменты_ии-llm-усиливает-инженера.md).

---

## Основная формула инженерного промпта

Хороший промпт включает **5 элементов**:

1. **Роль** — кто я / от чьего имени ты отвечаешь
2. **Контекст** — ситуация, проект, условия
3. **Задача** — что именно нужно сделать
4. **Ограничения** — что нельзя, что обязательно
5. **Формат ответа** — как оформить результат

### Шаблон

```
Ты опытный инженер-проектировщик светотехнической компании.

Контекст:
Проект: <описание проекта>
Условия: <температура, IP, срок, и т.д.>

Задача:
<что нужно получить>

Ограничения:
- <что нельзя>
- <что обязательно>

Формат ответа:
<структурированный текст / таблица / список>
```

## Типовые промпты для 7Lamp

### Промпт 1. Разбор ТЗ заказчика

```
Ты инженер-проектировщик светотехнической компании.
Я получил брифинг от заказчика (приложен ниже).

<текст брифинга>

Задача:
1. Выдели технические требования (мощность, CCT, IP, размеры, материал)
2. Найди двусмысленности и противоречия
3. Сформулируй 7-10 уточняющих вопросов заказчику

Формат ответа: маркированный список по каждому пункту.
```

### Промпт 2. Поиск альтернативного компонента

```
Найди 5 аналогов драйвера Mean Well HLG-40H-C700A.

Параметры важные:
- Мощность: 30-42 Вт
- Ток: 700 мА ± 5%
- Диапазон напряжения: 27-54 В DC
- КПД: не менее 88%
- IP67
- Поддержка диммирования 0-10V

Для каждого укажи:
- Производитель и модель
- Отличия от оригинала
- Цена (приблизительно, в рублях)
- Доступность в РФ на апрель 2026

Формат: таблица.
```

### Промпт 3. Расчёт теплового режима

```
Помоги прикинуть температуру перехода LED-модуля.

Исходные данные:
- LED: 20 шт. Samsung LM301B, ток 60 мА
- Тепловыделение на модуль: 130 мВт
- Радиатор: алюминиевый профиль, сечение 30×40 мм, длина 1000 мм
- Температура окружающей среды: +25°C
- Установка: на потолке, открытый монтаж

Задача:
1. Оцени площадь теплоотвода
2. Прикинь температуру корпуса радиатора
3. Посчитай температуру перехода LED (Tj)
4. Укажи, если превышается 85°C

Формат: пошаговый расчёт с формулами.
```

### Промпт 4. Написание ТЗ подрядчику

```
Напиши ТЗ для подрядчика по лазерной резке.

Задача:
Изготовить детали из приложенного DXF.

Параметры:
- Материал: алюминий 5052 H32, толщина 2 мм
- Количество: 50 шт
- Погрешность: ±0,1 мм
- Обработка кромок: удаление заусенцев, без фаски
- Маркировка: номер детали лазерной гравировкой

Стандартные требования 7Lamp:
- Направление проката: поперёк длинной стороны
- Упаковка: в картонную коробку, каждая деталь в отдельном пакете
- Сопроводительная документация: акт сдачи-приёмки

Формат ТЗ: стандартный документ с шапкой, разделами, подписью.
```

### Промпт 5. Сравнение технологий

```
Сравни 3 способа крепления торцевой заглушки к алюминиевому корпусу
дизайнерского светильника (масса светильника 3 кг):

1. Магниты N42, 15×3 мм, 2 шт.
2. Снап-фит (snap-fit) защёлка в PA12 (3D-печать SLS)
3. 2 потайных винта M3

Критерии:
- Эстетика (невидимость крепежа)
- Прочность удержания
- Число циклов разборки
- Стоимость
- Ремонтопригодность

Контекст 7Lamp:
- Производим мелкие серии 20-50 штук
- Заказчики — рестораны и офисы
- Обслуживание — раз в 2-3 года

Формат: таблица плюсов/минусов + итоговая рекомендация.
```

### Промпт 6. Объяснение стандарта

```
Объясни мне суть ГОСТ 14254-2015 применительно к моему проекту.

Мой проект:
Наружный настенный светильник для фасада. IP54. 
Условия: Москва, перепад температур от -30 до +35, дождь, снег.

Задача:
1. Кратко суть стандарта в 3-5 предложениях
2. Какие конкретные требования применимы к моему проекту
3. Что я должен проверить при конструировании
4. Какие нюансы легко упустить
```

### Промпт 7. Паспорт изделия

```
Напиши раздел "Инструкция по установке" для паспорта светильника.

Светильник:
- Линейный подвесной Line-1200
- Масса 2,5 кг
- Подвес на 2 стальных тросах ⌀1,5 мм, длина 1,5 м
- Питание 220 В, подключение через клеммник внутри светильника
- IP20

Аудитория: электромонтажник со средней квалификацией.

Требования:
- Понятный пошаговый язык
- Безопасность на первом месте
- Упомянуть требуемый инструмент
- Картинки/схемы не включать (будут добавлены отдельно)
- Объём: 1-2 страницы A4
```

## Анти-паттерны промптинга

### ❌ «Напиши мне ТЗ»

Слишком коротко. LLM не знает, на что ТЗ, для кого, в каком стандарте.

### ❌ «Рассчитай теплоотвод»

Нет исходных данных — LLM даст общую теорию без пользы.

### ❌ «Это лучше или то?»

Без критериев сравнения — случайный ответ.

### ✅ «Сравни по критериям X, Y, Z — какой вариант лучше для моих условий <условия>»

Чёткие критерии → чёткий ответ.

## Итеративные промпты

Хороший ответ редко приходит с первого раза. Работайте итерациями:

### Итерация 1. Базовый запрос

«Рассчитай тепловой режим LED-модуля...»

LLM даёт общий расчёт. Смотрите — что не учёл?

### Итерация 2. Уточнение

«Ты не учёл, что радиатор работает на обеих сторонах (LED сверху и снизу). Пересчитай с учётом этого.»

### Итерация 3. Проверка

«Теперь проверь мои данные: площадь теплоотвода 450 см² — это реалистично для профиля 30×40 длиной 1 м?»

### Итерация 4. Вывод

«Окей, финальный ответ с учётом всех поправок — какая температура перехода?»

## Шаблоны сохраняются

В 7Lamp есть практика хранения рабочих промптов:

1. Личная папка с часто используемыми промптами
2. Общая библиотека — с проверенными шаблонами под типовые задачи

Формат хранения — обычный текстовый файл `promts.md`:

```markdown
# Разбор ТЗ заказчика
<шаблон 1>

# Поиск аналога драйвера
<шаблон 2>
```

Копируете, вставляете, подставляете данные — ответ за секунды.

## Длина промпта

Страх «слишком длинного промпта» у инженеров редко оправдан. Современные LLM принимают:

* Claude — до 200K токенов (~150 000 слов)
* GPT-4o — до 128K токенов
* Gemini — до 1М токенов

Для сравнения: весь ГОСТ 14254 — это ~30K токенов.

**Правило:** если у вас есть релевантные данные — лучше дать их все, чем сэкономить.

## Контекст проекта

Для продолжительной работы с одним проектом — подготовьте **мастер-контекст**:

```
# Проект: Декоративный настенный светильник "Волна"

## Заказчик
Ресторан "Палитра"

## Требования
- 4000 K, 18 Вт, CRI > 90
- IP44 (наружная стена, под козырьком)
- Размер 600×200×50 мм
- Анодирование серое, покраска RAL 7016

## Срок
Проектирование до 10 мая 2026
Производство до 20 июня
Монтаж до 5 июля
```

В начале каждой сессии с LLM загружайте этот контекст — LLM «вспомнит», с чем мы работаем.

## Типовые ошибки

| Ошибка | Последствия | Решение |
|--------|-------------|---------|
| Слишком короткий промпт | Общий, непригодный ответ | Заполнить 5 элементов формулы |
| Нет ограничений | LLM придумывает своё | Явно указать нельзя/обязательно |
| Не указан формат | Плохо структурированный ответ | Таблица / список / пошагово |
| Забыл контекст | Несоответствие 7Lamp | Указать стандарты 7Lamp |
| Одна итерация и сдался | Упускаете сильные результаты | Уточнять, переспрашивать |
| Не сохраняешь промпт | Заново изобретаешь | Библиотека промптов |

## Чеклист перед отправкой промпта

* [ ] Указана роль (инженер, технолог, эксперт)
* [ ] Описан контекст проекта
* [ ] Чётко сформулирована задача
* [ ] Указаны ограничения и стандарты 7Lamp
* [ ] Задан формат ответа
* [ ] Для критичной задачи — указание верифицировать источники
* [ ] Промпт сохранён в библиотеку, если переиспользуемый
