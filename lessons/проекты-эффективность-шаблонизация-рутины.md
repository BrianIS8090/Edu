# Шаблонизация рутины — как сэкономить 30% времени

Инженер повторяет одни и те же действия каждый день: настройка слоёв Moi3D, оформление чертежа, заполнение спецификации, отправка писем подрядчикам. Если каждую такую задачу решать «с чистого листа» — уходит 30-40% рабочего дня на рутину. С шаблонами — 5-10%. Разница — это рабочая неделя в месяц. В этом уроке — какие задачи стоит шаблонизировать, как создавать рабочие шаблоны и почему это не «про лень», а про профессионализм.

---

## Какие задачи стоит шаблонизировать

Правило: **шаблонизируйте всё, что делаете больше 3 раз с похожей структурой**.

### Типовые кандидаты в 7Lamp

| Задача | Сколько раз в проекте | Экономия от шаблона |
|--------|-----------------------|---------------------|
| Настройка файла Moi3D | 1 | 10-15 мин |
| Рамка и штамп чертежа | 5-20 | 5 мин × N |
| Спецификация компонентов | 1-3 | 30-60 мин |
| Паспорт изделия | 1 | 2-4 часа |
| Заявка в производство | 5-10 | 20 мин × N |
| Коммерческое предложение | 1-2 | 1-3 часа |
| Отчёт о выполненной работе | 1 | 1 час |
| Письмо подрядчику | 3-10 | 5 мин × N |

**За типовой проект** — 15-25 часов на рутине без шаблонов. С шаблонами — 3-5 часов.

---

## Как создавать рабочий шаблон

### Шаг 1. Сделать задачу 3 раза

Пока не сделали задачу трижды — не понимаете её структуры. Первые попытки шаблонизации «с нуля» приводят к нерабочим заготовкам. Лучше сначала решить задачу по-живому, потом обобщить.

### Шаг 2. Выделить постоянное и переменное

Пройтись по выполненной задаче и разметить:

* **Постоянное** — не меняется от проекта к проекту (рамка чертежа, структура спецификации, шапка письма)
* **Переменное** — меняется (название проекта, дата, конкретные данные)

Постоянное идёт в шаблон как есть. Переменное — как «плейсхолдеры»: `<НАЗВАНИЕ ПРОЕКТА>`, `<ДАТА>`, `<ЗАКАЗЧИК>`.

### Шаг 3. Сделать заготовку

Создать файл-шаблон со всем постоянным содержимым и плейсхолдерами. Сохранить в:

* Личную библиотеку (если шаблон ваш)
* Общую библиотеку 7Lamp (если годится для всех)

### Шаг 4. Применить на следующей задаче

Следующий раз: открыть шаблон → заполнить плейсхолдеры → готово.

### Шаг 5. Доработка по ходу

После каждого применения — вопрос себе: что в шаблоне не хватило, что пришлось дописать? Добавить в шаблон. Через 3-5 применений шаблон стабилизируется.

## Шаблоны в Moi3D

### Главный шаблон файла

`7Lamp-template.3dm` — файл-заготовка с:

* Настроенными слоями (иерархия по стандарту 7Lamp)
* Стилями для материалов
* Цветами слоёв
* Предустановленными видами

Использование: `File → New from Template`, сохранить под именем проекта.

### Шаблоны сечений профилей

Для часто используемых профилей — готовые файлы с сечением, которое можно выдавить на нужную длину.

`PRO-015-Line30x40-Sechenie.3dm` — открывается, копируется в проект, выдавливается на нужную длину.

### Шаблоны сборочных узлов

Типовой узел подвеса, типовая крышка, типовые торцы — в виде готовых блоков, которые вставляются в проект.

## Шаблоны чертежей

### Рамка и штамп 7Lamp

Чертёжная рамка ЕСКД с полями для:

* Название проекта
* Обозначение чертежа
* Материал
* Масштаб
* Разработчик, проверил, утвердил
* Дата

Формат — `.dxf` или `.pdf`-шаблон для AutoCAD / LibreCAD.

### Шаблоны стилей

Стили линий, размеров, текста — одинаковые во всех чертежах 7Lamp. Хранятся в шаблоне и не настраиваются каждый раз.

### Типовые примечания

Стандартный блок примечаний, копируемый в каждый чертёж:

```
1. Неуказанные фаски C0,5 *.
2. Неуказанные предельные отклонения размеров по ГОСТ 25670-83.
3. Материал: алюминий 6063-T5 по ГОСТ 22233-2001 (если не указано иное).
4. Покрытие: анодирование по ГОСТ 9.301-86, цвет по образцу.
5. Маркировка: лазерная гравировка в соответствии с паспортом изделия.
```

Копируется в `General notes` любого чертежа.

## Шаблоны документов

### Спецификация компонентов

Excel-файл с готовой структурой:

| Поз | Наименование | Кол-во | Поставщик | Артикул | Цена | Примечания |
|-----|--------------|--------|-----------|---------|------|------------|
| 1 | | | | | | |

+ формулы для подсчёта суммы, + условное форматирование для подсветки «нет в наличии».

### Паспорт изделия

Word-шаблон с разделами:

1. Общие сведения
2. Технические характеристики
3. Комплект поставки
4. Схема монтажа
5. Инструкция по установке
6. Обслуживание и гарантия

Разделы постоянные — менять не надо. Переменные данные — в плейсхолдерах.

### Коммерческое предложение

Шаблон КП 7Lamp:

* Шапка с логотипом
* Описание проекта
* Табличная смета
* Сроки и условия оплаты
* Подпись

## Шаблоны писем и заявок

### Заявка в производство

Готовый шаблон для подрядчика:

```
Кому: <ПОДРЯДЧИК>
От: 7Lamp, инженер-проектировщик <ИМЯ>

Уважаемые коллеги,

Прошу изготовить детали согласно приложенной документации:
• Деталь 1: <НАЗВАНИЕ> - <КОЛ-ВО> шт
• Деталь 2: <НАЗВАНИЕ> - <КОЛ-ВО> шт

Материал: <МАТЕРИАЛ>
Сроки: <СРОК>
Комплектация: <ФОРМА ПОСТАВКИ>

Приложения:
• 3D-модели (STEP)
• 2D-чертежи (PDF)
• DXF для резки

С уважением,
<ИМЯ>
7Lamp
```

Заполняется за 2 минуты, а не пишется с нуля каждый раз.

### Отчёт о проекте

Шаблон с разделами:

1. Задача
2. Решение
3. Сроки
4. Стоимость
5. Риски и ограничения
6. Результат

Заполняется после закрытия проекта.

## Макросы и автоматизация

Для задач, которые выполняются десятками раз в проекте — стоит переходить от шаблонов к макросам.

**Примеры:**

* Горячая клавиша в Moi3D для типового набора операций
* Excel-макрос для пересчёта спецификации под новую валюту
* Скрипт для переименования файлов в папке по шаблону
* Скрипт для генерации 10 вариантов чертежа с разными размерами

См. урок [Автоматизация в Moi3D](lessons/проекты-эффективность-автоматизация-в-moi3d.md).

## Пример: шаблонизация паспорта изделия

**Задача:** сделать паспорт светильника быстрее.

### Без шаблона (4 часа)

1. Открываю новый Word-документ
2. Верстаю структуру — разделы, заголовки, форматирование
3. Добавляю логотип 7Lamp
4. Пишу тексты из памяти («нормы установки», «уход»)
5. Вставляю схему монтажа
6. Оформляю таблицу параметров
7. Проверяю, всё ли по шаблону ЕСКД

**Каждый паспорт — с нуля.**

### С шаблоном (40 минут)

1. Открываю `Passport-template.docx` из общей библиотеки
2. Заменяю плейсхолдеры на данные проекта
3. Вставляю схему монтажа из моделирования
4. Обновляю параметры в таблице
5. Сохраняю

**Качество выше, время — в 6 раз меньше.**

## Типовые ошибки

| Ошибка | Последствия | Решение |
|--------|-------------|---------|
| Шаблонизация с первого раза | Сделали нерабочую заготовку | Сначала 3 раза вручную |
| Слишком жёсткий шаблон | Не подходит под 30% случаев | Шаблон — заготовка, не догма |
| Шаблон без плейсхолдеров | Забыли поменять имя в КП на текущее | Плейсхолдеры в ` <УГЛОВЫХ СКОБКАХ>` |
| Не обновляют шаблон | Устаревает, теряет актуальность | Доработка после каждого применения |
| Сотрудничать со шаблонами = лень | Неправильное понимание | Шаблоны — это профессионализм |
| Нет центрального хранения | У каждого свои шаблоны, разнобой | Общая библиотека 7Lamp |

## Чеклист шаблонизации

* [ ] Задача сделана минимум 3 раза до шаблонизации
* [ ] Выделено постоянное и переменное содержимое
* [ ] Создан шаблон с плейсхолдерами
* [ ] Шаблон сохранён в личной или общей библиотеке
* [ ] Первое применение прошло успешно
* [ ] Замечания из применения учтены в шаблоне
* [ ] Коллеги знают о существовании шаблона (если общий)
* [ ] Есть периодический пересмотр шаблонов (раз в год)
