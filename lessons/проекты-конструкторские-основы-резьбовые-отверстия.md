# Резьбовые отверстия — как правильно подобрать

Резьбовое отверстие — это не просто круг с шагом, это конструктивный узел, от которого зависит, выдержит ли светильник вибрации при транспортировке и сохранит ли геометрию после сотен циклов сборки-разборки. В этом уроке — как выбрать размер резьбы под задачу, каким свёрлом сверлить под нарезание, какую глубину закладывать и чем отличается резьба в алюминии от резьбы в стали.

---

## Зачем инженеру разбираться в резьбе

Когда инженер ставит в модели `M4` «потому что привычно», начинается цепочка проблем:

* **Слишком мелкая резьба** — срывается при затяжке, на производстве жалуются и ставят заклёпку.
* **Слишком крупная резьба** — деталь становится толще, вес растёт, эстетика страдает.
* **Неправильный диаметр свёрла** — резьба режется с натягом или «болтается», соединение теряет прочность.
* **Недостаточная глубина** — резьба прорезается на 2 витка вместо 5, соединение выходит из строя.

Правильно подобранная резьба — это надёжность, технологичность и экономия металла. Ниже — рабочий минимум для конструктора 7Lamp.

---

## Метрическая резьба: что нужно знать

В проектах 7Lamp используется **метрическая резьба ISO** (ГОСТ 24705-2004). Обозначается буквой `M` и номинальным диаметром:

| Обозначение | Номинальный диаметр | Шаг (основной) |
|-------------|---------------------|----------------|
| M2 | 2,0 мм | 0,4 мм |
| M2,5 | 2,5 мм | 0,45 мм |
| M3 | 3,0 мм | 0,5 мм |
| M4 | 4,0 мм | 0,7 мм |
| M5 | 5,0 мм | 0,8 мм |
| M6 | 6,0 мм | 1,0 мм |
| M8 | 8,0 мм | 1,25 мм |
| M10 | 10,0 мм | 1,5 мм |

> **Правило:** если не знаете, какую резьбу ставить — ставьте M4 или M5. Это золотая середина по прочности, доступности инструмента и массе.

Мелкий шаг (`M6×0,75`, `M8×1`) применяется только там, где нужна повышенная точность позиционирования или работа в тонкостенном материале. В обычной конструкции светильника мелкий шаг — избыточная сложность.

## Таблица свёрел под нарезание резьбы

Диаметр отверстия под нарезание резьбы — не равен диаметру резьбы. Свёрло должно быть меньше, чтобы оставить материал под режущие витки метчика.

| Резьба | Диаметр свёрла | Примечание |
|--------|----------------|------------|
| M2 | 1,6 мм | Осторожно — метчик легко ломается |
| M2,5 | 2,05 мм | Стандарт для мелкой оптики |
| M3 | 2,5 мм | Массовый размер для LED-плат |
| M4 | 3,3 мм | Рабочая лошадка конструктора |
| M5 | 4,2 мм | Корпусные соединения |
| M6 | 5,0 мм | Силовой крепёж, подвесы |
| M8 | 6,8 мм | Кронштейны, основания |
| M10 | 8,5 мм | Потолочные подвесы, опоры |

> **Формула для запоминания:** диаметр свёрла = диаметр резьбы − шаг. Для M4×0,7: 4 − 0,7 = 3,3 мм.

Подрядчик сам подбирает свёрло, если в чертеже указана резьба по ГОСТ. Но инженер должен понимать, почему отверстие в модели сделано на 3,3 мм, а не на 4.

## Глубина резьбы и глубина отверстия

Глубина резьбы ≠ глубина отверстия. Это две разные величины, которые нужно указывать раздельно.

**Рабочее правило — минимальная глубина резьбы:**

| Материал | Глубина резьбы |
|----------|----------------|
| Сталь, латунь | 1,0 × D |
| Алюминий, дюралюминий | 1,5 × D |
| Пластик (ABS, PA) | 2,0 × D |
| Мягкий пластик (PETG) | Лучше запрессованная втулка |

`D` — номинальный диаметр резьбы. Для M4 в алюминии минимум 6 мм резьбы.

**Глубина отверстия — на 2-3 шага глубже резьбы.** Это запас под недорез метчика и сход стружки. Для M4 (шаг 0,7) при глубине резьбы 6 мм — отверстие 8-9 мм.

**Обозначение в чертеже:**

```
M4-6H ↓6
⌀3,3 ↓9
```

Первая строка — резьба и её глубина. Вторая — диаметр свёрла и глубина отверстия.

## Резьба в разных материалах

### Алюминий (основной материал 7Lamp)

Алюминий мягкий, резьба в нём работает нормально при соблюдении глубины `1,5×D`. Но при многократной разборке-сборке резьба срывается.

**Решения:**

* **Резьбовые втулки (хеликойл)** — вворачиваются в алюминий, создают стальную резьбу. Применяются там, где крепёж разбирают 10+ раз.
* **Резьбовые вставки «Ensat»** — самонарезающие, вкручиваются в отверстие без метчика. Хороши для серии.
* **Увеличенная глубина 2×D** — самый простой вариант, если есть место.

### Сталь

Работает всегда и везде. Глубина `1×D` достаточно. Проблема только в массе и стоимости обработки.

### Пластик (3D-печать, литьё)

В FDM-печати нарезанная резьба ненадёжна — слои расслаиваются. Варианты:

* **Запрессованная латунная втулка** — основной метод в прототипах 7Lamp
* **Моделирование резьбы напрямую в детали** — только для крупных M6+ и единичных случаев
* **Саморезы по пластику** — для неразборных соединений

## Пример из работы 7Lamp

**Задача:** закрепить LED-плату размером 20×100 мм на алюминиевом радиаторе. Плата имеет 2 монтажных отверстия ⌀2,5 мм.

**Решение:**

1. Выбираем резьбу **M2,5** — под штатные отверстия платы.
2. В радиаторе: отверстие ⌀2,05 мм под нарезание, глубина 7 мм.
3. Резьба M2,5-6H на глубину 5 мм (2×D для мягкого алюминия, плата разбирается при замене).
4. Винт **ISO 7045 M2,5×8** — с полукруглой головкой, чтобы не поцарапать текстолит.

**В чертеже:**

```
2 отв. M2,5-6H ↓5
     ⌀2,05 ↓7
```

## Типовые ошибки

| Ошибка | Что происходит | Как исправить |
|--------|----------------|---------------|
| Диаметр свёрла = диаметр резьбы | Метчик не режет, проворачивается | Проверить таблицу свёрел |
| Глубина резьбы = глубина отверстия | Метчик упирается, ломается | Отверстие на 2-3 шага глубже |
| Резьба M3 в алюминии толщиной 3 мм | Срывается за 2-3 сборки | Увеличить до M4 или добавить втулку |
| Нет обозначения резьбы в чертеже | Подрядчик ставит свою | Всегда указывать `M × шаг − класс ↓ глубина` |
| Нарезка резьбы в FDM-печати | Срывается, слои расходятся | Запрессованная втулка |

## Чеклист при проектировании резьбового отверстия

* [ ] Резьба подобрана под нагрузку, а не «по привычке»
* [ ] Диаметр свёрла взят из таблицы, а не равен диаметру резьбы
* [ ] Глубина резьбы ≥ 1,5×D для алюминия
* [ ] Глубина отверстия на 2-3 шага больше глубины резьбы
* [ ] В чертеже указаны обе величины: резьба и свёрло
* [ ] Для разборных соединений — заложена втулка или `2×D`
* [ ] Для пластика — запрессованная втулка или саморез
