# Формирование каталожного листа светильника

Каталожный лист — это визитная карточка светильника. Одна страница, которая решает, купят ваш продукт или пролистают дальше. Архитектор выбирает светильник по каталожному листу, тендерный комитет сверяет параметры, дилер показывает его заказчику. Если лист оформлен плохо или содержит устаревшие данные — вы теряете проект. В этом уроке — структура, источники данных и стандарт оформления 7Lamp.

---

## Что такое каталожный лист

**Каталожный лист** — одностраничное описание светильника в формате PDF. Содержит всё, что нужно для принятия решения: фото, чертёж, параметры, КСС, варианты исполнения.

Каталожный лист используется:

* На сайте 7Lamp — для скачивания посетителями
* В коммерческих предложениях — как приложение к спецификации
* В тендерной документации — для подтверждения характеристик
* Дилерами — для презентации заказчикам
* Архитекторами — для подбора светильников в проект

> Правило: один каталожный лист = одна серия или одна модель. Не пытайтесь уместить весь ассортимент на одной странице.

## Структура каталожного листа 7Lamp

Лист делится на шесть блоков, расположенных в определённом порядке.

### Блок 1. Фото изделия

Профессиональный рендер или фотография на белом (или нейтральном светло-сером) фоне. Требования:

* Разрешение не менее 300 dpi для печати
* Ракурс 3/4 — показывает и форму, и глубину
* Для встраиваемых — дополнительно вид снизу (виден рассеиватель)
* Нет посторонних предметов в кадре

### Блок 2. Габаритный чертёж

Упрощённый чертёж с ключевыми размерами:

* Длина × ширина × высота (в миллиметрах)
* Монтажные размеры (вырез в потолке для встраиваемых, межосевое для крепежа)
* Размер подвеса (длина троса, регулировка)

Чертёж берётся из Rhino (см. урок [Габаритные чертежи для каталога](lessons/проекты-3-этап-габаритные-чертежи-для-каталога.md)). Формат — векторный SVG или высококачественный PNG.

### Блок 3. Таблица параметров

Основной информационный блок. Структура таблицы:

| Параметр | Значение |
|---|---|
| Мощность | 40 Вт |
| Световой поток | 4 800 лм |
| Эффективность | 120 лм/Вт |
| CCT | 3000K / 4000K |
| CRI | ≥90 (R9 ≥50) |
| Угол луча | 90° (рассеянный) |
| IP | IP20 |
| Класс защиты | I |
| Размеры (Д×Ш×В) | 1196 × 60 × 55 мм |
| Вес | 1.8 кг |
| Материал корпуса | Алюминий 6063-T5 |
| Рассеиватель | Поликарбонат матовый |
| Диммирование | DALI-2, 0-10V |
| Напряжение питания | 220-240V AC, 50 Гц |
| Срок службы LED | L80B10 — 50 000 ч |
| Гарантия | 5 лет |

### Блок 4. Кривая силы света (КСС)

**Полярная диаграмма** — графическое представление распределения светового потока в пространстве. Обязательный элемент для профессиональных каталогов.

Откуда берётся КСС:

* Из файла IES/LDT (результат фотометрических измерений)
* Генерируется в DIALux, Relux или специализированном ПО
* Экспортируется как изображение (PNG с прозрачным фоном)

Для симметричных светильников достаточно одной полуплоскости (C0-C180). Для асимметричных — две полуплоскости (C0-C180 и C90-C270).

### Блок 5. Варианты монтажа

Иконки типов монтажа с подписями:

* Встраиваемый (иконка: утопленный в плоскость)
* Накладной (иконка: на поверхности)
* Подвесной (иконка: на тросах/штанге)

Для каждого варианта — краткое указание условий: «вырез в потолке 1210 × 70 мм» или «высота подвеса до 2 м».

### Блок 6. Опции и исполнения

Таблица доступных опций:

| Опция | Варианты |
|---|---|
| Цвет корпуса | RAL 9005 (чёрный), RAL 9003 (белый), RAL 9006 (серебро) |
| CCT | 2700K, 3000K, 4000K, Tunable White |
| Рассеиватель | Матовый, призматический, микропризма |
| Диммирование | Без, DALI-2, 0-10V, Casambi |
| Аварийный модуль | Без, 1 ч, 3 ч |
| Длина | 600, 900, 1200, 1500, 1800 мм |

## Откуда берутся данные

Каждый параметр каталожного листа имеет конкретный источник. Не выдумывайте цифры.

| Данные | Источник |
|---|---|
| Мощность, ток, напряжение | Протокол электрических измерений |
| Световой поток | Фотометрический протокол (интегрирующая сфера) |
| КСС | Файл IES/LDT (гониофотометр) |
| CRI, R9 | Фотометрический протокол |
| Размеры | 3D-модель в Rhino, проверенная штангенциркулем |
| Вес | Взвешивание серийного образца |
| Срок службы | Расчёт L80B10 по данным LED-производителя |
| IP-класс | Протокол испытаний по IEC 60529 |

> Никогда не указывайте параметры LED вместо параметров светильника. Заказчик покупает светильник, а не чип. 220 lm/W на LED ≠ 220 lm/W на светильнике.

## Формат и вёрстка

### Размер и ориентация

* Формат A4 (210 × 297 мм), вертикальная ориентация
* Поля: 15 мм со всех сторон
* Финальный файл: PDF, размер не более 3 МБ (для быстрой загрузки с сайта)

### Фирменный стиль 7Lamp

* Логотип в верхнем правом углу
* Акцентный цвет: #4f46e5 (индиго) — для заголовков и линий
* Шрифт заголовков: Segoe UI Bold
* Шрифт текста: Segoe UI Regular, 9-10 pt
* Артикул изделия крупным шрифтом под названием

### Инструменты создания

| Инструмент | Плюсы | Минусы |
|---|---|---|
| Adobe InDesign | Профессиональная типографика, мастер-страницы | Платный, требует навыков |
| Figma | Бесплатный, совместная работа, шаблоны | Нет автоматизации для серий |
| Canva | Быстро, шаблоны, drag-and-drop | Ограничения по типографике |
| Google Docs/Slides | Бесплатный, простой | Непрофессиональный результат |

Рекомендация 7Lamp: создайте шаблон в Figma, используйте его для всех серий. Шаблон обеспечивает единообразие и экономит время.

## Типичные ошибки

* **Устаревшие данные.** Световой поток на каталожном листе — 5000 лм, а по последнему протоколу — 4800 лм. Заказчик проверит и потеряет доверие
* **Нет КСС.** Профессиональный архитектор без КСС не сможет оценить светильник. Для тендеров КСС обязательна
* **Фото прототипа.** На листе рендер ранней версии, а в серии изменился рассеиватель. Заказчик получит не то, что ожидал
* **Нет артикула.** Без артикула менеджер не может оформить заказ, а заказчик не может сослаться на конкретную модель
* **Перегруженность.** Попытка уместить 5 серий на одной странице. Результат нечитаем. Один лист — одна серия
* **Нет контактов.** Забыли указать сайт, email или телефон. Заказчик хочет купить, но не знает куда звонить
