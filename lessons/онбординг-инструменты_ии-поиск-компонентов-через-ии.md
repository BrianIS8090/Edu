# Поиск компонентов и datasheet через ИИ

Инженер тратит значительную часть времени на поиск компонентов: найти подходящий драйвер, найти альтернативу LED-плате, найти коннектор под конкретную задачу. Через Google это занимает час на компонент: десятки ссылок, разные форматы datasheet, противоречия. LLM сокращает этот час до 10 минут — при условии, что вы умеете правильно пользоваться этим инструментом. В этом уроке — как эффективно искать компоненты через ИИ, какие подводные камни и как проверять результаты. Парные уроки — [Промпты для инженерных задач](lessons/онбординг-инструменты_ии-промпты-для-инженерных-задач.md), [Как LLM усиливает инженера](lessons/онбординг-инструменты_ии-llm-усиливает-инженера.md).

## Типовые задачи поиска компонентов

### Задача 1. Найти аналог по параметрам

«Нужен драйвер 40 Вт, 700 мА, диммируемый 0-10V, IP67, доступный в РФ».

### Задача 2. Найти компонент по описанию

«Коннектор для быстрого подключения кабеля 3×1,5 без пайки, IP65».

### Задача 3. Расшифровать datasheet

«Объясни, что означают параметры X, Y, Z в этой спецификации LED-платы».

### Задача 4. Сравнить варианты

«Сравни 3 оптических линзы Ledil для уличного освещения 30°».

### Задача 5. Оценить применимость

«Подойдёт ли этот LED-модуль для работы при +55°C?».

### Задача 6. Найти замену снятого с производства

«Замени DRV-XYZ, снятый с производства, на актуальный аналог».

LLM решает все шесть с разной степенью эффективности.

---

## Что LLM умеет (и что нет)

### Умеет

* Выдавать список возможных аналогов на основе обучения
* Расшифровывать параметры datasheet
* Сравнивать технические характеристики
* Переводить между единицами (мА ↔ Вт ↔ Лм)
* Находить типовые компоненты (Mean Well, Samsung LED, Ledil — известные)

### Не умеет

* Знать текущие цены
* Знать актуальную доступность в РФ
* Открывать актуальные datasheet с сайтов производителей
* Гарантировать, что конкретная модель до сих пор выпускается
* Учитывать санкционный статус импортных компонентов

Поэтому LLM — это **первый этап поиска**, не финальный.

## Шаблон промпта для поиска аналогов

```
Подбери 5 альтернатив для <оригинал>.

Критические параметры (должны быть близки):
- <параметр 1>: <значение ± допуск>
- <параметр 2>: <значение ± допуск>
- <параметр 3>: <значение ± допуск>

Желательные (по возможности):
- <параметр желательный>

Контекст:
- Доступность: <где берём — РФ, Китай, Европа>
- Бюджет: <в рублях за штуку>
- Серия: <штучно / 100 / 1000>

Для каждой альтернативы укажи:
- Производитель и модель
- Ключевые отличия от оригинала
- Ориентировочная цена
- Наличие в РФ (известные поставщики)

Формат: таблица.
```

## Пример: поиск аналога драйвера

**Запрос:**

```
Подбери 5 альтернатив для Mean Well HLG-40H-C700A.

Критические параметры:
- Мощность: 30-42 Вт
- Ток: 700 мА ± 5%
- Диапазон напряжения: 27-54 В DC
- КПД: не менее 88%
- IP67

Желательные:
- Диммирование 0-10V
- Поддержка PWM
- Работа при -40°C

Контекст:
- Доступность: РФ, приоритет — локальные склады
- Бюджет: до 2000 ₽/шт
- Серия: 200 шт

Для каждой укажи: производитель, модель, отличия, цена, где найти.

Формат: таблица.
```

**Ответ LLM (пример):**

| Производитель | Модель | Отличия от оригинала | Цена, ₽ | Где найти |
|---------------|--------|----------------------|---------|-----------|
| Helvar | LD40-C700-D | Меньше КПД (86%), но ниже цена | 1500 | ChipDip, ETM |
| Eaglerise | ESD-40W-C700D | Полный аналог, китайское качество | 1200 | Aliexpress |
| Tridonic | LC 35 700mA fixC | Выше КПД, лучше диммирование | 2200 | Светотехника-РФ |
| ... | ... | ... | ... | ... |

**Дальнейшие шаги:**

1. Проверяете каждую позицию — открываете сайт поставщика
2. Скачиваете свежий datasheet
3. Уточняете цену и наличие
4. Тестируете 1-2 модели на образцах

LLM сэкономил час на первичный отсев.

## Поиск по описанию (когда не знаете название)

**Задача:** нужен коннектор, не хотите паять, под кабель 3×1,5 мм², IP65, компактный.

**Промпт:**

```
Нужен коннектор для электрического подключения с характеристиками:
- Под кабель сечение 3×1,5 мм²
- Без пайки, быстрое соединение (защёлка / винт)
- IP65 или выше
- Максимальный ток 10 А
- Компактный, для установки внутри светильника

Какие существуют типы таких коннекторов?
Какие популярные бренды?
Какие модели подходят?

Контекст: дизайнерский светильник, нужна надёжность + эстетика.
```

**LLM расскажет про** пружинные клеммники Wago 221, 222, водонепроницаемые разъёмы IP65 от Phoenix Contact, китайские аналоги серии UL, ET. Дальше ищете вручную нужную модель.

## Расшифровка datasheet

LED-плата Samsung LM301B — datasheet на 20 страниц с параметрами, кривыми, графиками. Быстро понять ключевые параметры:

**Промпт:**

```
Я смотрю datasheet LED Samsung LM301B. Объясни мне простыми словами:

1. Что означают параметры:
   - Ra (CRI)
   - Bin Code
   - MacAdam ellipse
   - IF (Forward Current)
   - VF (Forward Voltage)

2. Какие значения этих параметров типичны для проектирования рабочего освещения в офисе?

3. На что обратить особое внимание при выборе конкретного бинкода для проекта?
```

LLM объяснит в понятных словах, выделит важное, предупредит о распространённых ошибках.

---

## Проверка результатов

LLM может ошибаться. Правила верификации:

### 1. Всегда открыть сайт производителя

Если LLM сказал «модель XYZ за 1500 ₽» — идёте на сайт производителя, проверяете:

* Модель существует?
* Datasheet соответствует описанному?
* Производится сейчас?

### 2. Проверить у нескольких поставщиков

Цена у одного — не истина. Запросить в 2-3 местах.

### 3. Сверить параметры

LLM мог перепутать один параметр. Пробежать ключевые значения глазами.

### 4. Проверить через каталоги

Если LLM называет модель — пробить её в официальном каталоге (Ledil, Mean Well, Osram).

### 5. Заказать образец перед серией

Для критичных компонентов — купить 1-2 шт, протестировать, и только потом заказывать партию.

---

## Интеграция с каталогами через MCP

Продвинутый подход — подключить LLM к каталогам через **MCP (Model Context Protocol)**. Пример:

* LLM подключен к API ChipDip / ETM
* LLM может реально искать компоненты, узнавать цены, проверять наличие
* Результаты — сразу актуальные, а не «из обучения»

Настройка — через Hermes Agent (см. урок [Hermes Agent](lessons/онбординг-инструменты_ии-Hermes_Agent.md)).

## Поиск замены снятого с производства

**Ситуация:** Проект эксплуатируется 5 лет, нужна замена перегоревшего драйвера. Оригинал — снят с производства.

**Промпт:**

```
Мой драйвер Mean Well HLG-40H-C700A снят с производства.
Нужен аналог, доступный в РФ на апрель 2026.

Параметры оригинала:
<список>

Критерии замены:
- Физические размеры должны позволить установку в корпус (60×40×30 мм)
- Электрические параметры близки
- Совместимость с существующим питанием 220В AC

Что заменяет Mean Well эту модель сейчас?
Какие китайские / европейские аналоги?
Какие нюансы при замене (габариты, кабели, пусковые токи)?
```

LLM даст несколько вариантов + предупредит про подводные камни.

## Типовые ошибки

| Ошибка | Последствия | Решение |
|--------|-------------|---------|
| Доверие без проверки | Заказан несуществующий компонент | Всегда проверка у поставщика |
| Одна модель LLM | Ограниченный кругозор | Использовать разные |
| Нет контекста доступности | Рекомендация не доступного в РФ | Явно указывать доступность |
| Игнор подводных камней | Сюрпризы на сборке | Задавать вопросы «что может пойти не так» |
| Не запрашивают цену | Превышение бюджета | Указывать бюджет в промпте |
| Пропуск параметров | Упущены важные параметры | Проверять по шаблону |
