# Пусконаладка систем управления освещением

Светильники смонтированы и подключены. Они включаются — но пока это просто лампочки на потолке. **Пусконаладка** превращает набор светильников в систему: адресация устройств, программирование сценариев, калибровка датчиков. После пусконаладки свет работает так, как задумано в проекте.

---

## Что такое пусконаладка

Пусконаладка систем управления освещением — это настройка аппаратных и программных компонентов после физического монтажа. Включает три основных блока:

* **Адресация** — присвоение уникальных адресов каждому устройству в сети
* **Программирование** — создание сценариев, групп, расписаний
* **Калибровка** — настройка датчиков присутствия и освещённости

Без пусконаладки система DALI — это 64 светильника, которые включаются и выключаются одним выключателем. После пусконаладки — это зонированное управление со сценариями, датчиками и автоматикой.

---

## Адресация DALI

### Основы адресации

**DALI** (Digital Addressable Lighting Interface) позволяет управлять каждым светильником индивидуально. Каждое устройство на DALI-линии получает уникальный адрес от 0 до 63. Максимум — 64 устройства на одну линию.

Устройства объединяются в **группы** (до 16 групп). Группа — это логическая единица управления. Например: группа 1 — светильники у окна, группа 2 — центральная зона, группа 3 — коридор.

### Инструменты для адресации

| Инструмент | Производитель | Особенности |
|---|---|---|
| masterCONFIGURATOR | Tridonic | Работает с USB DALI-интерфейсом Tridonic |
| Helvar Toolbox | Helvar | Для контроллеров Helvar |
| DALI USB / DALI Cockpit | Lunatone | Универсальный, работает с любыми DALI-устройствами |
| zenControl | zencontrol | Облачная платформа, мобильное приложение |

### Процедура адресации

1. **Подключите DALI-интерфейс** к линии (USB-интерфейс к ноутбуку + два провода к DALI-линии)
2. **Запустите ПО** и выполните сканирование линии. Программа обнаружит все подключённые устройства
3. **Присвойте адреса.** Автоматически (программа назначает последовательно) или вручную (вы выбираете адрес для каждого устройства, включая его для идентификации)
4. **Создайте группы.** Перетащите устройства в группы по зонам. Одно устройство может входить в несколько групп
5. **Проверьте.** Отправьте команду каждой группе (включить, выключить, диммировать до 50%) и убедитесь, что откликаются правильные светильники

> Совет: при ручной адресации включайте светильник на 100% и ищите его глазами на объекте. Так вы точно знаете, какой адрес какому физическому светильнику соответствует.

## Настройка сценариев освещения

**Сценарий** — это заранее запрограммированный набор уровней яркости для каждой группы. Вызывается одной командой: нажатием кнопки, сигналом датчика или по расписанию.

### Типовые сценарии для офиса

| Сценарий | Группа «Окно» | Группа «Центр» | Группа «Коридор» |
|---|---|---|---|
| Рабочий | 80% | 100% | 70% |
| Презентация | 30% | 40% | 20% |
| Перерыв | 50% | 50% | 50% |
| Ночной / уборка | 0% | 30% | 30% |
| Всё выключено | 0% | 0% | 0% |

### Типовые сценарии для ресторана

| Сценарий | Основной зал | Бар | Подсветка |
|---|---|---|---|
| Дневной | 100% | 80% | 50% |
| Вечерний | 40% | 60% | 100% |
| Романтический | 20% | 30% | 80% |
| Уборка | 100% | 100% | 100% |

### Программирование сценариев

В DALI каждое устройство хранит до 16 сценариев (Scene 0 — Scene 15). Программирование:

1. Установите яркость каждого светильника / группы на нужный уровень
2. Сохраните текущее состояние как сценарий (Store Scene X)
3. Привяжите вызов сценария к кнопке, датчику или расписанию
4. Проверьте переключение между сценариями — переходы должны быть плавными (fade time 1-3 секунды)

## Программирование датчиков

### Датчики присутствия

**Датчик присутствия** включает свет при обнаружении движения и выключает после задержки. Параметры настройки:

* **Зона обнаружения.** Угол и радиус. Для потолочного датчика на высоте 3 м — диаметр покрытия 6-8 м
* **Чувствительность.** Высокая — реагирует на мелкие движения (набор текста). Низкая — только на ходьбу
* **Задержка выключения.** Время после последнего движения до выключения. Типично: 10-15 минут для офиса, 5 минут для санузла, 3 минуты для коридора
* **Режим работы.** Полностью автоматический (включает и выключает) или полуавтоматический (только выключает, включение — вручную)

### Датчики освещённости

**Датчик освещённости** (daylight sensor) регулирует яркость искусственного света в зависимости от естественного. Параметры:

* **Уставка (setpoint).** Целевая освещённость на рабочей плоскости. Для офиса — 500 лк по СП 52.13330
* **Зона измерения.** Датчик измеряет освещённость в определённой точке. Он должен «видеть» рабочую плоскость, а не прямой солнечный свет
* **Мёртвая зона (deadband).** Диапазон, в котором датчик не реагирует. ±10% от уставки предотвращает постоянное подстраивание

### Комбинированные датчики

Современные датчики совмещают присутствие и освещённость в одном корпусе. Логика:

1. Человек вошёл → датчик присутствия активирует группу
2. Датчик освещённости проверяет уровень естественного света
3. Если естественного света достаточно (>500 лк) — искусственный не включается
4. Если недостаточно — искусственный свет добирает до уставки
5. Человек ушёл → задержка → свет выключается

## Тестирование системы

После программирования проведите полное тестирование.

### Чеклист тестирования

- [ ] Каждый сценарий вызывается и отрабатывает корректно
- [ ] Переходы между сценариями плавные (fade time настроен)
- [ ] Кнопки/выключатели вызывают правильные сценарии
- [ ] Датчики присутствия реагируют во всей зоне покрытия
- [ ] Датчики присутствия не реагируют за пределами зоны (ложные срабатывания)
- [ ] Задержка выключения соответствует настройке
- [ ] Регулировка по дневному свету работает корректно (прикрыть окно — свет увеличивается)
- [ ] Аварийный режим: при отключении DALI-линии светильники переходят на 100% (fail-safe)
- [ ] Ночной режим / расписание работает по времени

### Типичные проблемы при тестировании

| Проблема | Причина | Решение |
|---|---|---|
| Светильник не откликается | Нет DALI-адреса или обрыв линии | Проверить адресацию, проверить провод |
| Мерцание при диммировании | Несовместимость драйвера с протоколом | Заменить драйвер или изменить минимальный уровень |
| Датчик «видит» отражение | Глянцевый пол или зеркало в зоне | Изменить угол датчика, заклеить часть линзы |
| Помехи на DALI-линии | Провод проложен рядом с силовым кабелем | Развести трассы, использовать экранированный провод |
| Свет не выключается | Задержка датчика слишком большая | Уменьшить delay time |

## Передача заказчику

После успешного тестирования передайте систему заказчику.

### Что передать

* **Инструкция по управлению** — простой документ для пользователя: как включить сценарий, как настроить яркость, куда звонить при проблемах
* **Паспорт системы** — технический документ: адреса устройств, группы, сценарии, настройки датчиков
* **Обучение персонала** — 30-минутное обучение ответственного сотрудника (обычно администратор здания)
* **Контакты сервиса** — телефон и email инженера 7Lamp для вопросов и перенастройки

### Обучение персонала

Объясните пользователю:

* Как переключать сценарии (кнопки, панель, мобильное приложение)
* Как вручную изменить яркость (если нужно)
* Чего НЕ делать (не отключать DALI-линию выключателем, не перемещать датчики)
* Куда обращаться при проблемах
