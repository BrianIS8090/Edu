# Моделирование развёрток под гибку в Moi3D

Развёртка — это 2D-раскрой гнутой детали для резки лазером. Из 3D-модели гнутого кронштейна нужно получить плоский чертёж с линиями гиба, чтобы подрядчик отрезал лист и согнул. В SolidWorks есть готовая функция «развернуть» — в Moi3D её нет. Но развёртку всё равно можно сделать — методами, которые подходят прямому моделированию. В этом уроке — как получить корректную развёртку без плагинов и параметрики. Парный урок — [Проектирование под гибку](lessons/проекты-4-этап-проектирование-под-гибку.md).

---

## Почему в Moi3D нет автоматической развёртки

Автоматическая развёртка в параметрических CAD работает так: программа хранит историю гибов (где линия гиба, какой радиус, какой k-фактор) и может «развернуть» обратно, применив формулы bend allowance.

В Moi3D истории нет, есть только геометрия. Поэтому:

* Автоматически посчитать bend allowance невозможно — непонятно, где гиб
* Развернуть криволинейную поверхность на плоскость — сложная задача
* Готового инструмента «Flat Pattern» в базе Moi3D нет

Но есть три рабочих подхода.

---

## Подход 1: Подрядчик считает сам

Это **основной метод в 7Lamp**. Инженер делает:

1. 3D-модель согнутой детали (результат — как должна выглядеть готовая)
2. Чертёж с конечными размерами
3. Материал и толщина листа

Подрядчик на своём оборудовании (обычно SolidWorks или специализированный софт для ЧПУ пресса) считает развёртку и передаёт на лазер для резки.

**Плюсы:**

* Инженер не тратит время на развёртку
* K-фактор использует реальный (для оборудования и материала подрядчика)
* Меньше ошибок — подрядчик делает то, что он делает каждый день

**Минусы:**

* Инженер не видит, как выглядит развёртка — не может проверить её разумность
* Если подрядчик меняется — развёртки пересчитываются

Подходит для: прототипов, единичных изделий, малых серий.

---

## Подход 2: Ручная развёртка в Moi3D

Если нужна развёртка для самостоятельной отправки на лазер — её строят вручную. Процесс:

### Шаг 1. Подготовка модели

1. Модель не должна содержать фасок и сложных скруглений, только «острые» гибы
2. Все гибы — одинаковый радиус (например, R1)
3. Толщина листа постоянная по всей детали

### Шаг 2. Разбиение на плоские сегменты

Гнутая деталь состоит из плоских секций, соединённых радиусами гибов. Задача — выделить эти секции как отдельные плоскости.

1. **Просмотр детали сверху** — виден контур
2. **Построение каждой плоскости отдельно** — с размерами «как если бы деталь не была согнута»

### Шаг 3. Расчёт длины развёртки

Для каждого гиба считается **bend allowance (BA)** по формуле из урока [Проектирование под гибку](lessons/проекты-4-этап-проектирование-под-гибку.md):

```
BA = π × (R + k×t) × α / 180°
```

Для гиба 90°, алюминия 1 мм, R=1, k=0,33:
`BA ≈ 2,09 мм`

### Шаг 4. Построение плоской развёртки

В Moi3D на отдельном слое «Развёртка»:

1. Нарисовать первую плоскую секцию в натуральную величину
2. К её краю пристыковать следующую секцию через bend allowance
3. Между секциями провести **линию гиба** — она станет индикатором для подрядчика
4. Продолжать для всех секций

### Шаг 5. Обозначение линий гиба

Линии гиба в DXF для лазера обозначаются:

* **Punktir** — пунктир (распознаётся большинством станков)
* **Отдельный слой** — в DXF
* **Текстовая метка** — «гиб вверх 90° R1»

### Шаг 6. Экспорт в DXF

1. Выделить всю развёртку на слое «Развёртка»
2. `File → Export Selected` → DXF
3. Проверить в просмотрщике DXF

## Подход 3: Через Rhino + плагин Unroll

В 7Lamp часть инженеров использует связку **Moi3D + Rhino**:

1. В Moi3D проектируется деталь в 3D
2. Экспорт в `.3dm` в Rhino
3. В Rhino — команда `UnrollSrf` или плагин `RhinoFlatten`, `FlatWorm`
4. Получается плоский контур с учётом bend allowance

Для Rhino 7+ эта команда встроена. Результат — DXF развёртки.

**Плюсы:**

* Автоматический расчёт развёртки
* Учёт k-фактора
* Быстрее ручного

**Минусы:**

* Нужен Rhino (платный)
* Отдельный workflow

## Пример: развёртка U-образного кронштейна

**Задача:** развернуть кронштейн 100×50×60 мм, алюминий 2 мм, R гиба = 2 мм, 2 гиба 90°.

### Размеры в согнутом виде

* Основание: 100 мм
* Боковые стенки: 50 мм каждая

### Расчёт bend allowance для одного гиба

```
BA = π × (2 + 0,33×2) × 90 / 180
BA = π × 2,66 × 0,5
BA ≈ 4,18 мм
```

### Длина развёртки

```
L_развёртки = L_полка1 + BA + L_основание + BA + L_полка2
L_развёртки = (50 - 2) + 4,18 + (100 - 2×2) + 4,18 + (50 - 2)
L_развёртки = 48 + 4,18 + 96 + 4,18 + 48
L_развёртки ≈ 200,4 мм
```

**Без учёта BA** получилось бы `50 + 100 + 50 = 200 мм`. С учётом — **200,4 мм**. Разница кажется маленькой, но для серии даёт брак.

### В Moi3D

1. На слое «Развёртка»: прямоугольник 200,4 × ширина детали
2. Две вертикальные линии-гиба на расстояниях 48 мм от краёв
3. Отверстия размещены относительно этих линий
4. Экспорт в DXF с обозначением линий гиба

---

## Отверстия в развёртке

Отверстия в согнутой детали должны попасть в правильное место развёртки. Простое правило:

**Расстояние от края полки до отверстия** — в согнутом виде и в развёртке одинаковое.
**Расстояние от линии гиба до отверстия** — в развёртке считается от линии гиба.

Пример: отверстие ⌀5 мм на расстоянии 15 мм от линии гиба. В развёртке оно остаётся на тех же 15 мм от линии. Но если требуется, чтобы после гиба оно оказалось на расстоянии 13 мм от края соседней полки — нужно пересчитать с учётом отступа на радиус.

**Практический подход:** размеры отверстий на развёртке делаются от **линий гиба**, а не от внешних краёв детали — это снимает ошибки.

## Типовые ошибки при развёртке

| Ошибка | Последствия | Решение |
|--------|-------------|---------|
| Не учтён bend allowance | Деталь на 1-5 мм длиннее/короче | Считать по формуле для каждого гиба |
| K-фактор взят «с потолка» | Ошибка в 0,5-1 мм на гиб | Согласовать с подрядчиком |
| Разные радиусы гибов без учёта | Развёртка неправильная | Один радиус на деталь |
| Нет линий гиба в DXF | Подрядчик гнёт «на глаз» | Пунктир + слой |
| Отверстие точно на линии гиба | Вырвет при гибке | Минимум 2×t + R от линии |
| Развёртка отправлена без указания материала | Подрядчик режет из неподходящего листа | Приписывать материал к DXF |

## Чеклист отправки развёртки подрядчику

* [ ] 3D-модель согнутой детали есть и проверена
* [ ] Материал и толщина листа указаны в чертеже
* [ ] Bend allowance посчитан для всех гибов (или выбран подход 1)
* [ ] Линии гиба в DXF — на отдельном слое, пунктиром
* [ ] Направление гиба (вверх/вниз) указано
* [ ] Проверено расположение отверстий относительно гибов
* [ ] DXF открывается корректно в просмотрщике
* [ ] Сохранена 3D-модель для контроля
