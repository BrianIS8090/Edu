# Матрица «форма → технология» — выбор метода изготовления

Дизайнер прислал скетч изогнутого светильника. Вопрос инженера: из чего и как это сделать? Варианты — гибка алюминия, экструзия, литьё, 3D-печать, фрезеровка. Каждая технология даёт свою форму, свою стоимость, свой срок. Неправильный выбор на этом этапе — провал проекта: либо дорого, либо нельзя сделать, либо выглядит не так. В этом уроке — методика выбора технологии под форму и матрица решений для типовых случаев 7Lamp. Парный урок — [Mood-board и референсы](lessons/проекты-1-этап-mood-board-и-референсы.md).

## Ключевые технологии 7Lamp

| Технология | Характер формы | Когда применять |
|-----------|-----------------|-----------------|
| **Экструзия алюминия** | Линейная, постоянное сечение | Линейные светильники, профили |
| **Гибка листового металла** | Плоскости и сгибы | Кронштейны, простые корпуса |
| **Лазерная резка + гибка** | Комбинированные формы из листа | Декоративные панели, корпуса |
| **Фрезеровка листа** | Плоские вырезы сложной геометрии | Декоративные вставки |
| **3D-печать FDM/SLA/SLS** | Любая геометрия | Прототипы, мелкая серия |
| **Литьё пластика** | Сложные формы пластика в серии | 1000+ деталей |
| **Литьё алюминия** | Массивные металлические формы | Силовые детали |
| **Сварка** | Соединение деталей в силовые узлы | Подвесы, кронштейны |
| **Токарная обработка** | Круглые детали (вал, втулка) | Точные крепления |

## Матрица: форма → технология

### По характеру формы

| Характер формы | Подходящие технологии |
|----------------|----------------------|
| **Линейная, постоянное сечение** | Экструзия |
| **Плоские поверхности под углами** | Гибка листа |
| **Кривые поверхности** | Гибка + растяжка, 3D-печать, литьё |
| **Сферические / купольные** | Литьё, 3D-печать, штамповка |
| **Решётки / матрицы** | Лазерная резка, SLS |
| **Мелкие сложные элементы** | SLA / 3D-печать, литьё по выплавляемой модели |
| **Массивные детали** | Литьё, фрезеровка из заготовки |

### По серии

| Серия | Технологии |
|-------|-----------|
| **1-5 шт (прототип)** | 3D-печать, ручная гибка, лазерная резка |
| **10-50 шт (малая серия)** | 3D-печать SLS, экструзия + резка, лазер + гибка |
| **100-500 шт (серия)** | Экструзия, лазерная резка, SLS, литьё пластика |
| **1000+ шт (массовая)** | Экструзия, литьё, штамповка |

### По точности

| Точность | Технологии |
|---------|-----------|
| ±0,5 мм (свободно) | FDM, ручная сборка |
| ±0,1 мм (обычно) | Лазер, гибка, SLS, токарка |
| ±0,05 мм (точно) | SLA, фрезеровка CNC |
| ±0,01 мм (прецизионно) | Прецизионная фрезеровка, электроэрозия |

## Алгоритм выбора технологии

### Шаг 1. Описать форму

Формулируете в 2-3 предложениях:

* «Линейный профиль 1500 мм с пазом под LED»
* «Гнутый кронштейн 100×50 мм с тремя отверстиями»
* «Декоративная заглушка с рельефной поверхностью»

### Шаг 2. Определить объём

* Прототип (1-3 шт)?
* Мелкая серия (10-50 шт)?
* Серия (100-500 шт)?
* Большая серия (1000+ шт)?

### Шаг 3. Определить точность

* Насколько критична геометрия?
* Нужна ли видимая гладкость поверхности?
* Как соединяется с другими деталями?

### Шаг 4. Определить бюджет

* Стоимость в пересчёте на единицу
* Начальные инвестиции (матрица, форма)

### Шаг 5. Проверить матрицу

По критериям — какие технологии подходят? Обычно остаётся 2-3 варианта.

### Шаг 6. Сравнить плюсы/минусы

По каждому варианту — стоимость, срок, качество, риски.

### Шаг 7. Принять решение

Часто — оптимум между стоимостью и качеством.

## Типовые сценарии 7Lamp

### Сценарий 1. Линейный светильник Line-1200

**Форма:** прямой линейный светильник 1200 мм, сечение 30×40 мм.

**Серия:** 50 шт/год (регулярно).

**Выбор:**

* Экструзия (готовый профиль из каталога) → резка в размер → сверление → анодирование
* Стоимость корпуса: 800-1200 ₽/шт

**Альтернатива:** лазерная резка + гибка из листа — но дороже и менее эстетично.

### Сценарий 2. Декоративный светильник "Волна"

**Форма:** S-образный гнутый лист 600×200 мм.

**Серия:** 20 шт.

**Выбор:**

* Лазерная резка алюминия 2 мм → гибка по радиусу → анодирование
* Стоимость: 2500-4000 ₽/шт

**Альтернатива:** литьё алюминия — дорого для 20 шт, SLS — дорого и менее эстетично.

### Сценарий 3. Декоративная решётка

**Форма:** матрица отверстий 50×50 мм, 100 отверстий разных диаметров.

**Серия:** 200 шт.

**Выбор:**

* Лазерная резка алюминия 3 мм → анодирование
* Стоимость: 400-700 ₽/шт

**Альтернатива:** фрезеровка — дорого, штамповка — нужна матрица за 200 тыс.

### Сценарий 4. Кронштейн-уголок

**Форма:** L-образный, 100×50 мм, два отверстия M6, ребро жёсткости.

**Серия:** 500 шт.

**Выбор:**

* Листовая сталь → лазер → гибка → цинкование
* Стоимость: 150-250 ₽/шт

**Альтернатива:** литьё — дорого, фрезеровка — дорого.

### Сценарий 5. Эксклюзивная декоративная деталь

**Форма:** сложная органическая форма с гладкой поверхностью.

**Серия:** 50 шт.

**Выбор:**

* SLS → обработка поверхности → покраска
* Стоимость: 1500-3000 ₽/шт

**Альтернатива:** литьё из силикона на мастер-модели SLA — красивее, но сложнее логистика.

### Сценарий 6. Прозрачный рассеиватель

**Форма:** плоский лист с скруглёнными кромками.

**Серия:** 100 шт.

**Выбор:**

* Лазерная резка поликарбоната → полировка кромок
* Стоимость: 300-500 ₽/шт

**Альтернатива:** литьё — нерентабельно для такой серии.

## Комбинирование технологий

Редко форма делается одной технологией. Типовые комбинации в 7Lamp:

### Экструзия + лазерная резка

Профиль + листовые торцевые заглушки. Самая распространённая комбинация.

### Экструзия + фрезерные пазы

Профиль + боковые окна (фрезерованные). Для скрытого монтажа или вентиляции.

### Литьё + токарка

Литая деталь + токарная доработка посадочных мест.

### 3D-печать + доработка

SLS-деталь + просверленные отверстия под резьбу.

### Сварка + гибка

Стальной кронштейн из гнутых элементов + сварной шов для жёсткости.

---

## Когда технология определяет форму

Часто начинается обратный процесс: выбрали технологию, она диктует форму.

* **Экструзия выбрана** → форма должна быть с постоянным сечением
* **Гибка выбрана** → все сгибы из плоскости, радиусы ≥ 1×t
* **Литьё выбрано** → уклоны от линии разъёма, радиусы в углах
* **3D-печать выбрана** → свободная форма, но с учётом поддержек

**Это не ограничение — это тест на целесообразность.** Если дизайнер хочет форму, несовместимую с бюджетной технологией, выбор:

1. Адаптировать форму под технологию (дешевле)
2. Сменить технологию (дороже, но сохраняется форма)

## Типовые ошибки

| Ошибка | Последствия | Решение |
|--------|-------------|---------|
| Выбор технологии без учёта серии | Серия 500 шт через FDM — ужас | Всегда учитывать объём |
| Игнорирование начальных инвестиций | Матрица литья 500 тыс для 50 шт | Считать TCO |
| Оптимизация только стоимости | Самая дешёвая может не подойти | Баланс стоимости и качества |
| Одна технология на всю деталь | Упущение возможностей | Комбинировать |
| Не консультируются с подрядчиком | Форма невозможна технологически | Обсудить на этапе концепта |
| Выбор без тестирования | Сюрпризы в серии | Прототип обязателен |

* [ ] Для нестандартных — прототип согласован
