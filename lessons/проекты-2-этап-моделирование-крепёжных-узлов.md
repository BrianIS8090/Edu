# Моделирование крепёжных узлов — типовые решения 7Lamp

Крепёжный узел — это соединение светильника с поверхностью установки: потолком, стеной, тросом, фермой. В 7Lamp накоплена библиотека из 15-20 типовых узлов, которые переиспользуются от проекта к проекту. Инженеру не нужно каждый раз изобретать: большинство задач закрывается адаптацией готового решения. В этом уроке — обзор типовых крепёжных узлов и методика их моделирования в Moi3D. Парные уроки — [Соединения и крепёж](lessons/проекты-4-этап-соединения-и-крепёж.md), [Типовые узлы крепления](lessons/проекты-8-этап-типовые-узлы-крепления.md).

## Типовые крепёжные узлы 7Lamp

### 1. Накладной на потолок / стену

Самый простой узел — светильник прикручивается прямо к поверхности.

**Конструктив:**

* Задняя стенка корпуса с 2-4 отверстиями под дюбель
* Отверстия овальные — регулировка положения на ±3 мм
* Головки винтов скрыты внутри корпуса

**Типовое применение:** подсветка интерьера, бра, настенные светильники.

### 2. Подвес на трос

Для подвесных светильников — линейных Line, декоративных моделей.

**Конструктив:**

* Кронштейн с отверстием ⌀2-3 мм под зажим троса
* Тросовый зажим (покупной, ETM / LEDPred)
* Ответная часть в потолке — розетка с креплением на шуруп/дюбель

**Особенности:**

* Регулировка длины подвеса производится монтажом
* Уровень светильника выставляется натяжением двух/четырёх тросов
* Для лёгких светильников (до 3 кг) — один трос + упор
* Для тяжёлых — четыре троса по углам

### 3. Подвес на кабеле-тросе

Для подвесных линейных светильников, где кабель подключения одновременно является несущим.

**Конструктив:**

* Розетка в потолке с креплением кабеля
* Кабель армирован внутри стальным тросом
* Светильник имеет ввод для армированного кабеля
* Внутри — контактная группа и кабельный зажим

**Плюсы:** скрытая подводка питания, элегантный вид.
**Минусы:** дороже обычного троса, ограниченная длина (до 3 м).

### 4. Подвес жёсткий на штоке

Для светильников, которые не должны раскачиваться — над барными стойками, столами.

**Конструктив:**

* Штанга-труба ⌀16-22 мм из стали или алюминия
* Крепление к потолку через фланцевую розетку
* Крепление к светильнику через соответствующий фланец
* Длина штанги — кратна 100 мм для типоразмеров

### 5. Встраиваемый в потолок

Для Downlight, встроенных линеек.

**Конструктив:**

* Монтажное кольцо или рама с пружинными зажимами
* Корпус заходит в потолочный вырез
* Пружины фиксируют в потолке
* Декоративная шторка снаружи

**Требования:**

* Вырез в потолке согласовать с подрядчиком по монтажу
* Термозазор 2-3 мм для теплого корпуса
* Класс защиты IP20 (пылевлагозащита обычно не нужна)

### 6. Магнитная трек-система

Для ресторанов, выставочных залов — светильники перемещаются вдоль трека.

**Конструктив:**

* Магнитный адаптер 48V (стандарт рынка)
* Адаптер питания с магнитным замком
* Трек ставится отдельной компанией или покупается готовый

### 7. На кронштейне-опоре (для фасадов)

Для наружного освещения фасадов.

**Конструктив:**

* Кронштейн-угольник из стали
* Крепление к фасаду анкерами M10-M12
* Светильник крепится к кронштейну шарнирно (регулировка угла)
* Затяжка фиксирующим винтом

### 8. Прищепка / клипса

Для экспозиционных систем, временного монтажа.

**Конструктив:**

* Подпружиненный зажим
* Толщина зажимаемой кромки 2-30 мм
* Регулируемое усилие зажима

## Методика моделирования крепёжного узла

### Шаг 1. Определение типа узла

По ТЗ понять:

* Куда крепится (потолок бетонный / гипсокартон / ферма / трос)
* Какая нагрузка (вес светильника + коэффициент 4× запаса)
* Какие требования к виду (скрытый / открытый)
* Нужна ли регулировка (поворот, наклон, длина)

### Шаг 2. Выбор из библиотеки

Библиотека крепёжных узлов 7Lamp (см. урок [Общая библиотека 7Lamp](lessons/проекты-эффективность-общая-библиотека-7lamp.md)) содержит готовые STEP-модели основных типов. Выбирается ближайший по параметрам.

### Шаг 3. Адаптация

Готовый узел адаптируется под проект:

* Размеры под конкретную поверхность
* Отверстия под крепёж выбранного типа
* Цвет/покрытие под дизайн светильника

### Шаг 4. Встраивание в модель светильника

Крепёжный узел импортируется в файл светильника и размещается в нужном месте. Привязка к корпусу — через резьбовые или сквозные отверстия.

### Шаг 5. Проверка монтажа

Виртуальная проверка:

* Есть ли доступ к затяжке крепежа?
* Не мешает ли узел проводке / плате?
* Не пересекается с линзой / рассеивателем?

### Шаг 6. Документация узла

Для паспорта светильника (см. урок [Шаблон паспорта 7Lamp](lessons/проекты-6-этап-шаблон-паспорта-7lamp.md)):

* Схема монтажа узла
* Необходимые инструменты
* Последовательность сборки на месте
* Запас прочности

## Расчёт нагрузки на крепёжный узел

Каждый узел должен выдерживать вес светильника с 4-кратным запасом (стандарт безопасности).

**Формула:**

```
F_расч = m × g × k_зап
```

Где:

* `m` — масса светильника, кг
* `g` — 9,81 м/с²
* `k_зап` — коэффициент запаса = 4

**Примеры:**

| Светильник | Масса | F_расч |
|------------|-------|--------|
| Компактный накладной | 0,5 кг | 19,6 Н ≈ 2 кг |
| Line-1200 | 3 кг | 118 Н ≈ 12 кг |
| Large decorative | 15 кг | 590 Н ≈ 60 кг |
| Фасадная подсветка | 50 кг | 1962 Н ≈ 200 кг |

**Крепёж должен выдержать F_расч.** Для компактного достаточно M4 дюбеля. Для 50 кг — анкерные болты M10-M12.

## Пример: моделирование узла подвеса Line-1200

**Задача:** линейный светильник Line-1200, масса 2,5 кг, подвес на 2 троса длиной 1,5 м.

**Расчёт:**

* F_расч = 2,5 × 9,81 × 4 = 98 Н ≈ 10 кг → на 2 троса = 5 кг на трос
* Трос ⌀1,5 мм выдерживает до 50 кг → с большим запасом

**Элементы узла:**

1. **Розетка потолочная** ⌀60 мм, отверстия под 2 троса и кабель питания
2. **Тросовые зажимы** × 4 (по 2 на каждом тросе)
3. **Кронштейны светильника** 2 шт., привёрнуты к корпусу сверху
4. **Трос** стальной ⌀1,5 мм, длина 1500 мм

**Моделирование в Moi3D:**

1. Розетка — импорт из библиотеки, адаптация ⌀ отверстий
2. Кронштейны — моделирование под крепление к верху корпуса (2 винта M4)
3. Тросы — простые линии, не моделируются геометрически
4. Зажимы — упрощённые модели из библиотеки

**Итого:** 4 компонента узла, время моделирования 15-20 минут при использовании библиотеки.

## Типовые ошибки

| Ошибка | Последствия | Решение |
|--------|-------------|---------|
| Нет запаса прочности | Подвес обрывается через год | Минимум 4× запас |
| Крепёж стандартный на фасад | Ржавчина за год наружных условий | Нержавейка, горячее оцинкование |
| Не учтена вибрация | Откручивается от транспорта, ветра | Гровер / Loctite / Nord-Lock |
| Монтажник не имеет доступа к болту | Долгий монтаж, рекламация | Проверить сборку виртуально |
| Крепёж из каталога без адаптации | Не подходит под конкретный проект | Адаптировать или заказать спецверсию |
| Нет схемы монтажа в паспорте | Монтажник сверлит не в тех местах | Схема обязательна |

## Чеклист крепёжного узла

* [ ] Определён тип узла (накладной / подвес / встраиваемый)
* [ ] Рассчитана нагрузка с запасом ≥ 4×
* [ ] Выбран соответствующий нагрузке крепёж
* [ ] Для наружных условий — материал стоек к коррозии
* [ ] Есть доступ к затяжке крепежа на монтаже
* [ ] Предусмотрена регулировка положения (при необходимости)
* [ ] Узел взят из библиотеки или заложен в неё после проектирования
* [ ] Схема монтажа подготовлена для паспорта
