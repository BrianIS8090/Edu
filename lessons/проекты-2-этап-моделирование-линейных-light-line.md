# Моделирование линейных светильников Line — end-to-end

Линейные светильники Line — самая массовая серия 7Lamp. На каждом проекте инженер моделирует очередной светильник из каталожного профиля. В этом уроке — пошаговый рабочий процесс от выбора профиля до готовой модели с чертежами: как за 30-40 минут пройти путь, на который у новичка уходит 4 часа. Парные уроки — [Проектирование под экструзию](lessons/проекты-4-этап-проектирование-под-экструзию.md), [Top-down моделирование](lessons/проекты-2-этап-top-down-моделирование.md).

---

## Почему линейные — особый случай

Линейный светильник имеет особенности, которые делают его workflow отличным от дизайнерских:

* **Стандартный профиль** — не проектируется, берётся из библиотеки
* **Стандартные торцы** — типовые заглушки с незначительными вариациями
* **Длина — главный параметр** — 600, 900, 1200, 1500, 1800 мм
* **LED-модули кратны длине** — расчёт шага и количества

Вместо поиска формы — подбор из готового. Вместо моделирования с нуля — использование шаблонов.

## Пошаговый workflow

### Шаг 1. Определение параметров

Перед открытием Moi3D:

1. **Длина светильника** — по ТЗ или каталогу
2. **Мощность** — определяет выбор LED-платы и драйвера
3. **Температура свечения** — 2700/3000/4000/5000 K
4. **IP-класс** — IP20 для помещения, IP44+ для улицы
5. **Тип установки** — подвесной, накладной, встраиваемый

Без этих данных моделирование начинать нельзя.

### Шаг 2. Выбор профиля из библиотеки

Библиотека сечений 7Lamp (см. урок [Общая библиотека](lessons/проекты-эффективность-общая-библиотека-7lamp.md)) содержит готовые STEP-файлы профилей на 1 метр длины. Алгоритм:

1. Открыть каталог профилей — Moi3D-файл или бумажная подборка
2. Выбрать подходящий по габаритам и конструкции
3. Скопировать STEP в папку проекта

Критерии выбора:

* Сечение позволяет разместить нужную LED-плату
* Тепловыделение соответствует мощности (массивные для 40+ Вт)
* Паз под рассеиватель если нужно
* Паз для крепления кронштейнов

### Шаг 3. Создание рабочего файла

Открываем шаблон `7Lamp-template.3dm` (см. урок [Организация проекта Moi3D](lessons/проекты-2-этап-организация-проекта-moi3d.md)). Слои уже настроены.

Сохраняем как `line-1200-v1.3dm` в папку `/3-модель/`.

### Шаг 4. Построение корпуса

1. **Импорт сечения профиля** — `File → Import → Merge` → STEP из библиотеки
2. **Проверка сечения** — оно должно быть замкнутым плоским контуром в XY-плоскости
3. **Выдавливание** — `Construct → Extrude` на нужную длину (например, 1200 мм)
4. **Привязка к слою «Корпус»** — чтобы не пропал в общем хаосе

Проверка: объём должен соответствовать реальному (для грубой оценки).

### Шаг 5. Торцевые заглушки

Из библиотеки берётся шаблон торцевой заглушки под выбранный профиль. Подгоняется:

1. **Импорт** заглушки как отдельного объекта
2. **Размещение** на левом торце корпуса (X = 0)
3. **Копирование** (`Transform → Copy`) на правый торец (X = 1200)
4. **Зеркалирование** правой заглушки (если асимметричная)
5. **Слой «Торцы»**

Если стандартной заглушки нет — моделируется под конкретный проект, но это редко.

### Шаг 6. Крепёжные отверстия

На профиле — резьбовые бобышки для крепления крышки. На заглушках — сквозные отверстия.

1. Построить **одну группу** отверстий с резьбой M3/M4 в профиле
2. Построить **одну группу** отверстий под винт в заглушке
3. **Размножить** — `Transform → Array → Linear` по длине с нужным шагом

Для 1200 мм типичный шаг — 250 мм, то есть 5-6 крепёжных точек.

### Шаг 7. LED-плата и драйвер

Вставка упрощённых моделей:

1. **LED-плата** — прямоугольник нужных габаритов, толщина 1 мм. Позиционирование на дне паза профиля.
2. **Драйвер** — блок с габаритами по datasheet, размещается либо внутри корпуса (массивный профиль), либо выносной.

Модели упрощённые — чтобы проверить размещение и зазоры, а не реалистичность.

### Шаг 8. Рассеиватель / линза

Если профиль имеет паз под рассеиватель:

1. **Импорт** рассеивателя из библиотеки (или моделирование из сечения)
2. **Вставка** в паз профиля
3. **Проверка** положения относительно LED

### Шаг 9. Проверка сборки

Финальный прогон:

* [ ] Стыки между деталями без зазоров и наложений
* [ ] LED-плата не упирается в рассеиватель
* [ ] Доступ к драйверу есть (для обслуживания)
* [ ] Кабельный ввод в нужном торце

### Шаг 10. Сохранение версий

* `v1` — базовая модель
* После согласования — `v2-согласовано`
* Перед отправкой — `v3-финал-в-производство`

## Типовые шаги для разных серий Line

### Line-600 (600 мм, 15 Вт)

1. Профиль малого сечения 15×20
2. LED-плата 10×550 мм
3. Драйвер выносной (внутри не поместится)
4. Крепёж — 2-3 точки
5. Время моделирования: 20-30 мин

### Line-1200 (1200 мм, 30 Вт)

1. Профиль среднего сечения 25×40
2. LED-плата 15×1150 мм
3. Драйвер внутри нижней камеры
4. Крепёж — 4-5 точек
5. Время моделирования: 30-40 мин

### Line-1800 (1800 мм, 50 Вт)

1. Профиль большого сечения 30×60
2. LED-плата разрезана на 2 × 900 мм с коннектором
3. Драйвер внутри, в отдельной камере
4. Крепёж — 6-7 точек
5. Тепловой расчёт обязателен
6. Время моделирования: 50-60 мин

## Пример: Line-1200, Ш-образный профиль

**Исходные данные:**

* Длина 1200 мм
* Мощность 30 Вт
* LED-плата Samsung LM301B, 3000 K
* IP20, накладной монтаж
* Корпус белый, анодированный алюминий

**Моделирование:**

1. Профиль `LEDPred-Line30x40-W` из библиотеки → импорт → extrude на 1200
2. Торцевые заглушки (левая, правая) — из библиотеки
3. LED-плата 10×1150, 1 мм — на дне паза
4. Драйвер Mean Well HLG-40H-C350A — в нижней камере
5. Рассеиватель матовый, толщина 2,5 мм — в пазу сверху
6. Крепёжные отверстия M4×4 с шагом 300 мм
7. Кабельный ввод M16×1,5 — правый торец

**Итоговый файл:** 14 объектов, 4 слоя, 35 минут работы.

## Типовые ошибки

| Ошибка | Симптом | Решение |
|--------|---------|---------|
| Моделирование профиля с нуля | Потраченный час на уже существующее | Брать из библиотеки |
| Не задана длина LED-платы | Конфликт с торцевыми заглушками | Плата = длина корпуса − 50 мм |
| Забыт кабельный ввод | Невозможно подключить | Обязательный элемент |
| Драйвер не помещается | Заказ выносного ИП | Проверять габариты до моделирования |
| Рассеиватель без зазора | Деформация при нагреве | Зазор 0,5-1 мм с двух сторон |
| Крепёжные точки одинаковы по всей длине | Тепловое расширение ведёт корпус | Одна точка базовая, остальные овальные |
| Файл без версий | Потеряны предыдущие варианты | `v1`, `v2`, `v3` дисциплинированно |

## Чеклист моделирования Line

* [ ] Исходные параметры зафиксированы (длина, мощность, CCT, IP)
* [ ] Профиль выбран из библиотеки
* [ ] Торцевые заглушки — из библиотеки или собраны под проект
* [ ] LED-плата и драйвер размещены с учётом габаритов
* [ ] Тепловой расчёт проведён (для 30+ Вт)
* [ ] Рассеиватель установлен с компенсационным зазором
* [ ] Крепёжные отверстия по шагу 250-300 мм
* [ ] Одна точка базовая, остальные с овальной регулировкой
* [ ] Кабельный ввод заложен
* [ ] Файл сохранён по стандарту именования
