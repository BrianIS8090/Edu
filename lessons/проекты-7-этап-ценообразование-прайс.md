# Ценообразование и формирование прайс-листа

Инженер проектирует светильник, а руководство назначает цену. Но инженерные решения определяют себестоимость, а значит — нижнюю границу цены. Понимание ценообразования позволяет инженеру принимать решения, которые делают продукт не только хорошим, но и продаваемым. В этом уроке — путь от себестоимости к розничной цене, система скидок и позиционирование относительно конкурентов.

---

## От себестоимости к розничной цене

Цена изделия формируется послойно. Каждый слой добавляет стоимость.

### Цепочка ценообразования

```
Себестоимость
  + Целевая маржа 7Lamp
  = Отпускная цена (B2B)
    + Наценка дилера/дистрибутора
    = Розничная цена (если применимо)
```

### Пример для линейного светильника LINE 1200

| Слой | Сумма | Комментарий |
|---|---|---|
| Себестоимость | 7 400 руб. | Из расчёта (см. урок «Расчёт себестоимости») |
| Маржа 7Lamp (45%) | 3 330 руб. | Покрытие операционных расходов + прибыль |
| **Отпускная цена** | **10 730 руб.** | Цена для прямых клиентов и дилеров |
| Наценка дилера (30%) | 3 219 руб. | Доход партнёра |
| **Розничная цена** | **13 949 руб.** | Цена для конечного заказчика через дилера |

> Инженер не устанавливает цену. Но инженер, понимающий ценообразование, проектирует светильник, который можно продать.

## Факторы, определяющие маржу

Маржа — не фиксированный процент. Она зависит от контекста проекта и типа продукции.

| Фактор | Влияние на маржу | Типичный диапазон |
|---|---|---|
| **Серийная продукция** | Маржа стандартная, объём компенсирует | 35-45% |
| **Кастомные изделия** | Маржа выше — включает проектирование | 50-80% |
| **Тендер** | Маржа минимальна для победы | 15-25% |
| **Стратегический клиент** | Маржа ниже ради долгосрочных отношений | 25-35% |
| **Уникальный продукт** | Нет аналогов — маржа максимальна | 60-100% |
| **Крупная партия (50+ шт)** | Маржа ниже за единицу, выше общая прибыль | 30-40% |

### Минимальная допустимая маржа

Ниже определённого порога продавать невыгодно — даже если заказ крупный. Минимальная маржа должна покрывать:

* Операционные расходы компании (аренда, зарплаты, коммуникации)
* Гарантийные обязательства (резерв на замены и ремонт — 3-5%)
* Риски (дефицит компонентов, рост цен, брак)

Для 7Lamp минимальная маржа — 20%. Ниже — только по решению руководства для стратегически важных проектов.

## Формирование прайс-листа

Прайс-лист — основной коммерческий документ. Менеджеры по продажам, дилеры и архитекторы работают именно с ним.

### Структура прайса

| Колонка | Содержание |
|---|---|
| Серия | Название серии (LINE, SPOT, FLOOD) |
| Артикул | Уникальный код изделия |
| Описание | Краткое описание (тип, мощность, CCT) |
| Мощность | В ваттах |
| Световой поток | В люменах |
| CCT | Цветовая температура |
| IP | Степень защиты |
| Размеры | Д×Ш×В |
| Цена без НДС | Отпускная цена B2B |
| Цена с НДС | Для конечных заказчиков |
| Опции | Доступные модификации |

### Принципы формирования

* **Логика серий.** Группируйте по сериям, внутри серии — по мощности (от меньшей к большей)
* **Единообразие.** Все цены в одной валюте, единый формат
* **Дата действия.** Обязательно указывайте дату — «Прайс-лист от 01.04.2026»
* **Версионность.** Нумеруйте версии (v1.0, v1.1, v2.0)

## Система скидок

Скидки — инструмент продаж. Но бессистемные скидки убивают маржу. В 7Lamp действует структурированная система.

### Типы скидок

| Тип скидки | Размер | Условие |
|---|---|---|
| Объёмная | 5-15% | От 20 светильников одного типа |
| Дилерская | 20-35% | Договор дилера, закупочная квота |
| Проектная | 5-10% | Комплексный проект (проектирование + поставка) |
| Повторная закупка | 3-5% | Клиент возвращается с новым заказом |
| Акционная | 10-20% | Распродажа остатков, продвижение новых серий |

### Правила предоставления скидок

* Скидки **не суммируются** — применяется наибольшая
* Скидка свыше 15% — только с согласования руководителя отдела продаж
* Скидка свыше 25% — только с согласования генерального директора
* Скидка на кастомные изделия — не более 5% (себестоимость проектирования не масштабируется)

## Позиционирование относительно конкурентов

7Lamp — не самый дешёвый и не самый дорогой. Позиционирование: **средний-верхний сегмент с акцентом на инженерное качество**.

### Конкурентный анализ

Для ключевых серий периодически сравнивайте цены с конкурентами:

| Параметр | 7Lamp LINE 1200 | Конкурент A | Конкурент B |
|---|---|---|---|
| Мощность | 40 Вт | 38 Вт | 42 Вт |
| Световой поток | 4 800 лм | 4 200 лм | 4 600 лм |
| CRI | ≥90 | ≥80 | ≥90 |
| Диммирование | DALI-2 | 0-10V | DALI |
| Цена | 10 730 руб. | 8 500 руб. | 12 200 руб. |
| lm/руб. | 0.45 | 0.49 | 0.38 |

Аргументация для заказчика: «Наш светильник на 20% дороже конкурента A, но CRI 90 вместо 80 и DALI-2. На 12% дешевле конкурента B при сопоставимых параметрах».

### Когда конкурировать ценой, а когда — нет

* **Тендер с жёсткими ценовыми критериями** — конкурируйте ценой, минимизируйте маржу
* **Проект с архитектором/дизайнером** — конкурируйте качеством, формой, сервисом
* **Серийная поставка для ритейла** — конкурируйте соотношением цена/качество
* **Кастомный проект** — конкурировать ценой невозможно. Конкурируйте компетенцией

## Пересмотр прайса

Прайс-лист — живой документ. Он устаревает при любом изменении себестоимости.

### Когда пересматривать

* Изменение курса валют более чем на 10% (LED и драйверы — импорт)
* Рост стоимости алюминия более чем на 15%
* Снятие компонента с производства и замена на аналог
* Выход новых серий или модификаций
* Ежеквартальный плановый пересмотр (даже если ничего не изменилось — проверить актуальность)

### Процедура

1. Инженер пересчитывает себестоимость по актуальным ценам
2. Руководитель проверяет маржу — достаточна ли она
3. Отдел продаж обновляет прайс и уведомляет дилеров
4. Старый прайс архивируется с датой окончания действия
