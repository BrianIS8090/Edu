# Визуализация светильников для каталога и КП

Заказчик не видит STEP-файл — он видит картинку. Качественный рендер продаёт светильник до того, как его изготовят. Визуализация нужна для каталога на сайте, коммерческих предложений, тендерной документации и социальных сетей. В этом уроке разберём полный процесс — от выбора инструмента до финального файла, готового к публикации.

---

## Зачем нужна визуализация

Фотография готового изделия — идеальный вариант, но она доступна только после производства. На этапе проектирования единственный способ показать светильник заказчику — рендер.

Где используются визуализации в работе 7Lamp:

* **Каталог на сайте** — карточка каждого светильника содержит 3-4 ракурса на белом фоне
* **Коммерческое предложение (КП)** — рендер светильника в интерьере убеждает заказчика лучше таблицы с характеристиками
* **Тендерная документация** — визуализация показывает, что изделие существует как проработанное решение, а не абстрактная идея
* **Социальные сети и презентации** — эффектные ракурсы привлекают внимание и формируют имидж компании
* **Согласование с архитектором** — рендер в контексте помещения помогает утвердить дизайн до начала производства

> Один качественный рендер заменяет десять минут объяснений по телефону. Вкладывайте время в визуализацию — это инвестиция, которая окупается на этапе продаж.

## Выбор инструмента: KeyShot или Blender

Оба инструмента дают фотореалистичный результат. Разница — в подходе и стоимости.

| Критерий | KeyShot | Blender |
| --- | --- | --- |
| Стоимость | ~$1000 (лицензия) | Бесплатный |
| Порог входа | Низкий: перетащил модель, назначил материал, нажал рендер | Средний: нужно освоить интерфейс и ноды |
| Импорт из Rhino/Moi3D | Прямой импорт 3DM, STEP, OBJ | Импорт через OBJ, FBX, STEP (с плагином) |
| Скорость рендера | Быстрый на CPU, поддержка GPU | Cycles — GPU, быстрый на мощной видеокарте |
| Настройка материалов | Библиотека готовых материалов, drag-and-drop | Нодовый редактор, полный контроль |
| Анимация | Базовая (вращение, разрез) | Полноценная анимационная система |
| Постобработка | Встроенная (базовая) | Compositor — мощная встроенная постобработка |

**Рекомендация для инженера 7Lamp:** начните с KeyShot. Он даёт результат за 30 минут без глубокого изучения. Переходите на Blender, когда нужна анимация, сложные сцены или нет бюджета на лицензию.

## Настройка материалов для светильников

Материалы — основа реализма. Светильник 7Lamp обычно состоит из 3-4 материалов. Разберём настройку каждого.

### Анодированный алюминий

Самый частый материал корпуса. Анодирование создаёт тонкий оксидный слой с характерным мягким отражением.

* **Шероховатость (Roughness):** 0.25-0.35. Ниже — слишком зеркальный, выше — выглядит как порошковая покраска
* **Отражение (Reflectance):** металлический тип, базовый цвет — светло-серый (#C0C0C0) для натурального анодирования
* **Цветное анодирование:** измените базовый цвет. Чёрный анодированный — #2A2A2A с Roughness 0.30
* **Микроцарапины:** добавьте процедурную текстуру шума (Noise) с минимальной амплитудой в канал Roughness. Это создаёт эффект реальной обработки

### Порошковая покраска RAL 9005

Матовый чёрный — второй по популярности финиш после анодирования.

* **Тип:** диэлектрик (не металл)
* **Базовый цвет:** #0A0A0A (не чисто чёрный #000000 — в реальности абсолютного чёрного не бывает)
* **Шероховатость:** 0.55-0.70 для матового покрытия. Для полуглянца — 0.30-0.40
* **Текстура «апельсиновой корки»:** характерна для порошковой покраски. Добавьте Bump-карту с мелким шумом, высота 0.002-0.005 мм

### Матовый рассеиватель из поликарбоната

Рассеиватель пропускает и рассеивает свет. Это полупрозрачный материал — настройка сложнее.

* **Тип:** полупрозрачный (Translucent / Subsurface Scattering)
* **Цвет пропускания:** белый с лёгким желтоватым оттенком
* **Толщина:** соответствует реальной толщине детали (обычно 1.5-3 мм)
* **Шероховатость поверхности:** 0.60-0.80 для матового рассеивателя
* **IOR (индекс преломления):** 1.586 для поликарбоната

> В KeyShot используйте материал «Translucent» из библиотеки пластиков и подстройте параметры. В Blender — нодовая связка Principled BSDF с включённым Subsurface Scattering.

### Закалённое стекло

Используется в уличных и промышленных светильниках.

* **Тип:** стекло (Glass / Dielectric)
* **IOR:** 1.52 для обычного стекла
* **Шероховатость:** 0.0 для прозрачного, 0.30-0.50 для матированного
* **Цвет:** слегка зеленоватый оттенок (#F0FFF0) имитирует реальное стекло

## Настройка сцены

Правильная сцена определяет 80% восприятия рендера. Даже идеальные материалы выглядят плоско при неудачном освещении.

### HDRI-окружение

**HDRI** (High Dynamic Range Image) — панорамная фотография с расширенным динамическим диапазоном. Она одновременно служит источником освещения и отражений.

Для каталожных рендеров используйте студийные HDRI:

* Нейтральное студийное освещение — мягкие тени, ровное заполнение
* Избегайте уличных HDRI — цветные рефлексы на корпусе светильника искажают восприятие материала

Бесплатные HDRI: [Poly Haven](https://polyhaven.com/hdris) — раздел Studio.

### Студийный свет

Для полного контроля добавьте искусственные источники:

* **Key light (основной)** — мягкий прямоугольный источник сбоку-сверху, 45 градусов
* **Fill light (заполняющий)** — слабее основного в 2-3 раза, с противоположной стороны
* **Rim light (контровой)** — узкий источник сзади, выделяет контур светильника на фоне

### Фон

* **Для каталога:** чисто белый фон (#FFFFFF). Тень — мягкая, контактная, без резких краёв
* **Для КП и презентаций:** градиент от светло-серого к белому или размытый интерьер на заднем плане
* **Для социальных сетей:** допускается тёмный фон для драматичного эффекта

## Ракурсы для каталога

Стандартный набор ракурсов для каждого светильника в каталоге 7Lamp:

### Обязательные ракурсы

1. **Фронтальный вид** — светильник прямо перед камерой, чуть выше уровня глаз. Показывает общий облик
2. **Ракурс 3/4** — камера смещена на 30-45 градусов. Самый информативный вид: видны и фронт, и боковая грань
3. **Деталь крепления** — крупный план монтажного узла. Монтажник должен понять способ крепления с одного взгляда
4. **Вид снизу** (для встраиваемых) — как светильник выглядит из помещения после монтажа

### Дополнительные ракурсы

* **Разрез / взрыв-схема** — показывает внутреннюю структуру (LED-модуль, драйвер, радиатор)
* **Светильник в контексте** — смонтированный на потолке или стене, с имитацией светового потока
* **Группа светильников** — несколько штук в линию, демонстрация модульности

> Камера должна быть на уровне реального восприятия. Для потолочного светильника — чуть снизу. Для торшера — на уровне глаз стоящего человека.

## Рендер свечения

Работающий светильник на рендере — это отдельная задача. Нужно имитировать световой поток, не превратив картинку в засвеченное пятно.

### Источник света в сцене

Разместите площадной источник света (Area Light) в позиции LED-модуля. Цветовая температура — 3000K или 4000K (тёплый белый или нейтральный). Интенсивность подберите визуально: рассеиватель должен светиться, но детали корпуса не должны пропадать в засветке.

### Эффект bloom и glow

**Bloom** — мягкое свечение вокруг ярких областей. Создаёт ощущение реального источника света.

* В KeyShot — включите Bloom в настройках Image -> Bloom
* В Blender — добавьте Glare-ноду в Compositor (тип Fog Glow, порог 0.8-0.9)

### Баланс экспозиции

Главная сложность — показать одновременно светящийся рассеиватель и детали тёмного корпуса. Снизьте контраст сцены:

* Увеличьте заполняющий свет, чтобы тени не были абсолютно чёрными
* Используйте тональную компрессию (Tone Mapping) для сжатия динамического диапазона
* В постобработке поднимите тени, не трогая светлые области

## Постобработка

Рендер из движка — это полуфабрикат. Финальную картинку доводят в графическом редакторе.

### Обрезка и композиция

* Оставляйте отступ вокруг светильника — не менее 15% от габарита с каждой стороны
* Выравнивайте горизонтальные линии корпуса строго горизонтально
* Для каталога — центрируйте объект в кадре

### Цветокоррекция

* Баланс белого — нейтральный. Фон должен быть действительно белым, а не серым или желтоватым
* Контраст — умеренный. Избегайте «пережаренных» картинок с провалами в тенях
* Насыщенность — слегка приглушена. Промышленный продукт выглядит достовернее без кислотных цветов

### Формат для web

| Назначение | Формат | Разрешение | Размер файла |
| --- | --- | --- | --- |
| Каталог на сайте | JPEG | 1600 x 1200 px | 150-300 КБ |
| Карточка товара (миниатюра) | JPEG | 600 x 450 px | 40-80 КБ |
| КП (для печати) | PNG | 3000 x 2250 px | 1-3 МБ |
| Социальные сети | JPEG | 1080 x 1080 px | 100-200 КБ |

> Сохраняйте исходный рендер в формате EXR или PNG 16-bit. Это ваш «цифровой негатив» — из него всегда можно получить любой формат без потери качества.

## Стандарт визуализации 7Lamp

Для единообразия каталога соблюдайте следующие правила.

### Технические требования

* **Фон:** белый (#FFFFFF) для каталога, допускается светло-серый (#F5F5F5) для КП
* **Тень:** мягкая контактная, без резких краёв, непрозрачность 15-25%
* **Освещение:** нейтральное студийное, цветовая температура источников 5500K
* **Разрешение рендера:** не менее 3000 px по длинной стороне (для последующей обрезки)
* **Формат исходника:** EXR или PNG 16-bit

### Именование файлов

Формат: `[Код]_[Ракурс]_[Версия].png`

Примеры:

* `DL120_front_v01.png` — даунлайт 120 мм, фронтальный вид, версия 1
* `LIN600_34_v02.png` — линейный 600 мм, ракурс 3/4, версия 2
* `DL120_mount_v01.png` — деталь крепления
* `DL120_glow_v01.png` — с имитацией свечения

### Чеклист перед сдачей

1. Материалы соответствуют реальным (анодирование не выглядит как хром)
2. Нет артефактов: чёрных пятен, «шва» на поверхностях, шума
3. Пропорции светильника соответствуют модели (не искажены перспективой)
4. Белый фон действительно белый (проверьте пипеткой: R=G=B=255)
5. Файл именован по стандарту
6. Исходник в EXR сохранён в папку проекта
