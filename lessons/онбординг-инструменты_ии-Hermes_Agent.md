# Hermes Agent — установка и настройка

![Hermes Agent](assets/Hermes_Agent/banner.png)

**Hermes Agent** — самообучающийся AI-агент от [Nous Research](https://nousresearch.com) с замкнутым циклом обучения: создаёт навыки из опыта, запоминает контекст между сессиями и живёт не только в терминале, но и в Telegram, Discord, Slack. В этом уроке — как поставить Hermes на рабочую машину инженера 7Lamp, подключить к нему LLM-провайдера и запустить через Telegram, чтобы агент работал, пока вы заняты проектом.

---

## Зачем Hermes инженеру 7Lamp

Hermes — прямой наследник OpenClaw (см. [урок про OpenClaw](lessons/ии_и_агенты-инструменты_ии-Оpenclaw.md)), но с расширенным набором функций. Если OpenClaw жил в терминале, то Hermes:

* Работает с вами **из Telegram** — пишете боту, он отвечает, используя те же инструменты, что и в CLI.
* Запоминает контекст **между сессиями** — знает, какой проект вы делали вчера и какие компоненты использовали.
* Создаёт собственные **навыки** после решения задач и переиспользует их в будущем.
* Работает по **расписанию** — может каждое утро присылать сводку по задачам или раз в неделю делать бэкап.
* Делегирует задачи **подагентам** — параллельно обрабатывает несколько запросов.

На практике это даёт инженеру личного ассистента, который помнит всё про ваш стиль работы и доступен из любого мессенджера.

## Требования к системе

| Требование | Значение |
|------------|----------|
| ОС | Linux, macOS, WSL2, Android (Termux) |
| Python | 3.11+ (установится автоматически) |
| Оперативная память | 4 ГБ минимум, 8 ГБ рекомендуется |
| Дисковое пространство | 2 ГБ для базовой установки |
| Интернет | Нужен для облачных LLM. Для локальных моделей — опционально |

> **Важно для Windows:** нативная установка на Windows не поддерживается. Нужен [WSL2](https://learn.microsoft.com/ru-ru/windows/wsl/install) — подсистема Linux внутри Windows. Один раз настроили — и дальше работаете как на Linux.

## Установка на Windows через WSL2

Типовой сценарий для инженера 7Lamp — рабочая машина на Windows 11. Ставим WSL2 с Ubuntu и разворачиваем Hermes внутри.

### Шаг 1. Установка WSL2

Откройте PowerShell от имени администратора и выполните:

```powershell
wsl --install
```

Команда установит WSL2 и дистрибутив Ubuntu по умолчанию. После перезагрузки создайте пользователя Ubuntu и пароль.

### Шаг 2. Обновление Ubuntu

В терминале Ubuntu:

```bash
sudo apt update && sudo apt upgrade -y
sudo apt install -y curl git
```

### Шаг 3. Установка Hermes Agent

Один универсальный скрипт — работает на Linux, macOS, WSL2 и Termux:

```bash
curl -fsSL https://raw.githubusercontent.com/NousResearch/hermes-agent/main/scripts/install.sh | bash
```

Скрипт сам поставит Python 3.11, создаст виртуальное окружение и скачает зависимости. Занимает 3–5 минут.

### Шаг 4. Перезагрузка оболочки

```bash
source ~/.bashrc
hermes
```

Если команда `hermes` запустилась и показала TUI — установка прошла успешно.

## Подключение LLM-провайдера

Hermes не привязан к одной модели. Выбирайте провайдера под задачу и бюджет:

| Провайдер | Модели | Когда выбирать |
|-----------|--------|----------------|
| **OpenRouter** | 200+ моделей (Claude, GPT, Gemini, Llama) | Универсальный вариант для 7Lamp. Один ключ — все модели |
| **Anthropic** | Claude 4.7 Opus, Sonnet, Haiku | Для сложных инженерных задач, кода, анализа |
| **OpenAI** | GPT-4o, o1 | Для текстовой работы, генерации описаний |
| **NVIDIA NIM** | Nemotron | Для локальной инфраструктуры с GPU |
| **Hugging Face** | Открытые модели | Для экспериментов и приватных данных |

### Настройка провайдера

```bash
hermes model
```

Команда откроет интерактивный выбор: провайдер → модель → ввод API-ключа. Ключ сохраняется в `~/.hermes/config.yaml`.

> **Совет:** начните с OpenRouter — один API-ключ даёт доступ ко всем моделям, и вы сможете сравнивать их без переустановки.

### Быстрая смена модели в чате

Уже внутри разговора можно менять модель без перезапуска:

```
/model openrouter:anthropic/claude-4.7-opus
/model openai:gpt-4o
```

## Подключение Telegram

Самая полезная функция для инженера — писать Hermes из Telegram, когда вы на площадке или в дороге.

### Шаг 1. Создание бота

1. Откройте в Telegram чат с [@BotFather](https://t.me/BotFather).
2. Отправьте команду `/newbot`.
3. Задайте имя бота (например, `Hermes 7Lamp`) и username (например, `hermes_7lamp_bot`).
4. Скопируйте API-токен, который пришлёт BotFather.

### Шаг 2. Настройка шлюза в Hermes

```bash
hermes gateway setup
```

В интерактивном мастере выберите `Telegram`, вставьте токен и укажите свой Telegram ID (узнать можно через [@userinfobot](https://t.me/userinfobot)).

### Шаг 3. Запуск шлюза

```bash
hermes gateway start
```

После этого можно писать боту в Telegram — Hermes отвечает с того же контекста, что и в CLI.

> **Безопасность:** не добавляйте посторонних в allowlist. Бот выполняет команды от вашего имени и имеет доступ к файлам на машине.

## Основные команды CLI

| Команда | Назначение |
|---------|------------|
| `hermes` | Запуск интерактивного чата |
| `hermes model` | Выбор LLM-провайдера и модели |
| `hermes tools` | Настройка инструментов (какие включены) |
| `hermes config set` | Изменение отдельных параметров конфигурации |
| `hermes gateway` | Управление шлюзом мессенджеров |
| `hermes setup` | Полный мастер настройки |
| `hermes update` | Обновление до последней версии |
| `hermes doctor` | Диагностика проблем |

---

## Команды внутри чата

Работают одинаково и в CLI, и в Telegram:

| Команда | Действие |
|---------|----------|
| `/new` или `/reset` | Начать новую беседу с чистым контекстом |
| `/model [провайдер:модель]` | Сменить модель на лету |
| `/personality [имя]` | Сменить персону (набор инструкций) |
| `/retry` / `/undo` | Повторить или отменить последний ответ |
| `/compress` | Сжать контекст при приближении к лимиту токенов |
| `/usage` | Показать расход токенов |
| `/skills` | Посмотреть список навыков |
| `/stop` | Прервать текущую работу |
| `Ctrl+C` | То же, что `/stop`, но только в CLI |

## Миграция с OpenClaw

Если вы уже работали с OpenClaw — Hermes автоматически перенесёт настройки, навыки, ключи API и историю памяти.

```bash
hermes claw migrate --dry-run    # Посмотреть, что будет перенесено
hermes claw migrate              # Выполнить миграцию
```

Переносятся:

* `SOUL.md` — файл персоны
* `MEMORY.md` и `USER.md` — память агента
* Пользовательские навыки из `~/.openclaw/skills/`
* Разрешённые команды (approval patterns)
* Настройки мессенджеров и allowlist пользователей
* API-ключи (Telegram, OpenRouter, OpenAI, Anthropic, ElevenLabs)

> **Совет:** сначала запустите `--dry-run` — Hermes покажет, что именно перенесёт, без изменений.

## Типовые проблемы

### `command not found: hermes`

Оболочка не подхватила новую команду. Выполните:

```bash
source ~/.bashrc
```

Если не помогло — перезапустите терминал или проверьте, что `~/.local/bin` в `PATH`.

### Ошибка при первом запуске

```bash
hermes doctor
```

Диагностика покажет: какие зависимости отсутствуют, доступна ли сеть, валидны ли ключи API.

### Telegram-бот не отвечает

Проверьте:

* Процесс `hermes gateway` запущен и не упал
* Ваш Telegram ID есть в allowlist
* Токен бота скопирован полностью, без пробелов

### Высокий расход токенов

Включите команду `/compress` внутри чата — Hermes сожмёт историю, сохранив суть. Либо начните новую беседу через `/new`.
