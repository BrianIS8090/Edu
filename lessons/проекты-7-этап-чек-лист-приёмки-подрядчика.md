# Приёмка работ подрядчика — чек-лист инженера

Детали пришли от подрядчика. Инженер 7Lamp должен принять их правильно: проверить соответствие чертежу, измерить размеры, оценить качество поверхности, составить акт. Халатная приёмка — это брак в серии, рекламации заказчика, убытки 7Lamp. Систематическая приёмка по чек-листу — это спокойное качество и сохранение репутации. В этом уроке — рабочий чек-лист инженера и методика приёмки. Парные уроки — [Работа с браком](lessons/проекты-7-этап-работа-с-браком-от-подрядчика.md), [Оперативка с подрядчиком](lessons/проекты-7-этап-оперативка-с-подрядчиком.md).

---

## Что такое приёмка работ

Приёмка — официальный процесс:

1. Подрядчик передаёт детали
2. Инженер проверяет соответствие ТЗ и чертежам
3. При соответствии — подписывает акт приёмки
4. При отклонениях — оформляет претензию

С подписью акта — детали считаются принятыми, 7Lamp платит подрядчику. Ответственность за брак, выявленный позже, делится между сторонами (часто — на 7Lamp).

**Главный принцип:** не подписывать акт, пока не уверены в соответствии.

## Подготовка к приёмке

### Перед получением деталей

1. Распечатать чертежи — бумажные копии для сверки
2. Подготовить измерительный инструмент (см. ниже)
3. Освободить стол / рабочее место
4. Приготовить бирки для маркировки принятых / неподходящих
5. Запланировать 1-2 часа на каждую партию

### Измерительный инструмент

| Инструмент | Для чего |
|-----------|----------|
| **Штангенциркуль цифровой 0-150 мм** | Линейные размеры с точностью 0,01 мм |
| **Штангенциркуль механический 0-300 мм** | Большие размеры |
| **Микрометр 0-25 мм** | Точные толщины |
| **Угольник ГОСТ 3749** | Проверка прямых углов |
| **Угломер** | Углы наклона, скосы |
| **Щупы** | Зазоры сборочные |
| **Шаблоны радиусов** | Скругления и фаски |
| **Калибры резьбовые** | Проверка резьбы М-серии |
| **Шероховатомер или эталоны Ra** | Шероховатость поверхности |

В 7Lamp стандартный набор инженера — штангенциркуль, микрометр, угольник, угломер, щупы.

## Чек-лист приёмки детали

### 1. Комплектность

* [ ] Количество деталей соответствует ТЗ и накладной
* [ ] Упаковка соответствует требованиям (каждая деталь в пакете, коробка подписана)
* [ ] Сопроводительная документация приложена (акт сдачи-приёмки, паспорт партии)

**Если меньше по количеству:** зафиксировать в акте, не подписывать до выяснения.

### 2. Общий вид

Первая секунда — визуальная оценка:

* [ ] Нет видимых повреждений (вмятины, царапины, трещины)
* [ ] Цвет / покрытие соответствует образцу
* [ ] Гомогенность партии (все одинаковые)
* [ ] Нет загрязнений от производства

**Критерии отбраковки:**

* Глубокие царапины на видимых поверхностях
* Деформация формы (не соответствует 3D)
* Пропущенные операции (не просверлено, не покрашено)

### 3. Геометрические размеры

Для каждой детали — проверить **критические размеры из чертежа**.

В ТЗ 7Lamp критические размеры помечены красным или звёздочкой (*).

* [ ] Все критические размеры в допуске
* [ ] Габариты соответствуют чертежу ±0,5 мм (для некритичных)
* [ ] Отверстия в нужных местах с правильными диаметрами
* [ ] Резьбовые отверстия проходят калибр

**Выборочный контроль:** при партии 100+ шт — проверять 5-10% случайной выборкой.

### 4. Отверстия и резьба

* [ ] Сквозные отверстия — диаметр калибром ±0,1 мм
* [ ] Резьбовые отверстия — калибр-пробка проходит
* [ ] Фаски на входе резьбы есть
* [ ] Чистота нарезки резьбы (без задиров)

### 5. Качество обработки поверхности

* [ ] Шероховатость соответствует чертежу (сравнить с эталонами Ra)
* [ ] Удалены заусенцы (провести пальцем в перчатке — не зацепляет)
* [ ] Фаски и скругления без задиров
* [ ] Нет следов инструмента (царапин, борозд)

### 6. Гибы и углы (для гнутых деталей)

* [ ] Угол гиба соответствует чертежу ±1°
* [ ] Радиус гиба соответствует чертежу
* [ ] Нет трещин в области гиба
* [ ] Ровность линии гиба

### 7. Покрытие (если применимо)

Для анодирования:

* [ ] Цвет соответствует образцу (утверждённому)
* [ ] Нет пятен, потёков, пропусков покрытия
* [ ] Толщина покрытия (если критично — замер толщиномером)
* [ ] Нет контактных пятен (от подвески в ванне)

Для покраски:

* [ ] Цвет по RAL соответствует образцу
* [ ] Равномерность (нет пятен, подтёков)
* [ ] Адгезия (перекрёстный тест, если критично)
* [ ] Прочность (не скалывается при лёгком ударе)

### 8. Сварка (для сварных узлов)

* [ ] Швы без трещин и пор
* [ ] Непроваров нет (на просвет)
* [ ] Форма шва соответствует ГОСТ
* [ ] Зона термического влияния не пострадала

### 9. Сборочные свойства

Для комплектующих:

* [ ] Собирается с ответной деталью без доработки
* [ ] Зазоры в допуске
* [ ] Крепёж проходит и затягивается нормально
* [ ] Функциональные элементы работают (подвижные, пружинные)

### 10. Маркировка

* [ ] Есть маркировка партии (лазер / штамп / этикетка)
* [ ] Номер заказа соответствует ТЗ
* [ ] Маркировка не на видимой поверхности (если эстетично важно)

## Методика приёмки для разных объёмов

### 1-5 штук (прототипы / единичное)

Проверка **каждой детали** по всем пунктам чек-листа.

### 10-50 штук (малая серия)

* Каждая деталь — визуальный осмотр
* 100% — критические размеры
* 20-30% — все размеры

### 100-500 штук (серия)

* 100% — визуальный осмотр
* 10-15% выборки — критические размеры
* 5% — полная проверка по чек-листу

### 1000+ штук (массовая)

* Статистический контроль качества по ГОСТ 18242
* AQL 1-2,5 по ГОСТ 31814 (допустимый уровень дефектности)
* Акт подписывается при соответствии статистике

## Оформление акта приёмки

### Положительный случай

Акт о полном соответствии:

```
АКТ ПРИЁМКИ-ПЕРЕДАЧИ

От подрядчика: <ООО X>
Получатель: ООО "7Lamp"

Дата: <дата>
Заказ: <номер>

Наименование: <деталь>
Количество: <N> шт

Проверено по ТЗ / чертежу: <артикул>

Результат: СООТВЕТСТВУЕТ ТЕХНИЧЕСКИМ ТРЕБОВАНИЯМ

Принял: _______________ (инженер 7Lamp)
Передал: _______________ (представитель подрядчика)
```

### С частичным браком

Фиксируется:

* Общее количество
* Количество принятых (с пометкой «годны»)
* Количество с дефектами (в отдельный список)
* Описание дефектов
* Решение: возврат / доработка / замена

### С полным браком

Акт о несоответствии:

```
АКТ О НЕСООТВЕТСТВИИ

Партия не соответствует техническим требованиям.

Обнаруженные дефекты:
1. <описание>
2. <описание>

Количество дефектных: <N> из <N>
Результат: ОТКЛОНЕНО

Решение: возврат в производство для исправления
Срок устранения: <дата>

Инженер 7Lamp: _______________
Представитель подрядчика: _______________
```

## Документирование дефектов

Для каждого дефекта:

1. **Фотография** — видно дефект
2. **Описание** — что именно не так
3. **Замер** — конкретное значение отклонения от ТЗ
4. **Чертёж** — выделена проблемная зона
5. **Код дефекта** — по внутренней классификации 7Lamp

**Код дефектов 7Lamp:**

* `GEOMETRY` — отклонение геометрии
* `SURFACE` — дефект поверхности
* `COATING` — проблема покрытия
* `ASSEMBLY` — не собирается
* `QUANTITY` — нехватка
* `OTHER` — прочее

## Типовые ошибки

| Ошибка | Последствия | Решение |
|--------|-------------|---------|
| Подпись акта «на глазок» | Брак в серии обнаружен позже | Систематический чек-лист |
| Визуальная оценка без замеров | Размерные дефекты упущены | Инструментальный контроль |
| Не фотографировать дефекты | Нечем доказать | Фото с линейкой |
| Принимать неполную партию | Доклад позже — проблема | Неполная — не подписываем |
| Приёмка в плохом освещении | Дефекты не видны | Лампа 5000K, яркая |
| Спешить | Пропуск критичных дефектов | 1-2 часа минимум |
| Не проверять калибром | Резьба может быть «почти» | Калибр обязателен |
