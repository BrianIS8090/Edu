# Полный шаблон паспорта изделия 7Lamp

Паспорт изделия — официальный документ, который сопровождает каждый светильник 7Lamp от производства до гарантийного обслуживания. Это и юридический документ (обязателен по ТР ТС 004/2011), и инструмент коммуникации с заказчиком, и «лицо» качества. Сделанный халтурно паспорт — повод для возврата. Сделанный по шаблону — проходит все проверки и упрощает жизнь всем. В этом уроке — полный шаблон паспорта 7Lamp по разделам с методикой заполнения. Парный урок — [Инструкция по эксплуатации](lessons/проекты-6-этап-инструкция-по-эксплуатации.md).

---

## Зачем нужен паспорт

### Юридическая функция

По ТР ТС 004/2011 «О безопасности низковольтного оборудования» каждое изделие должно сопровождаться:

* Руководством по эксплуатации на русском
* Техническими характеристиками
* Информацией о безопасности
* Гарантийными обязательствами
* Информацией о производителе

Без паспорта светильник не проходит таможню, не принимается тендерными комиссиями, не может быть установлен на объектах с надзором.

### Коммерческая функция

Паспорт показывает уровень производителя. Хороший паспорт — аргумент в пользу 7Lamp при выборе между конкурентами. Плохой — повод отказаться от контракта.

### Сервисная функция

Через 3-5 лет нужна замена компонента. Кто делал? Какой модификации? Какой драйвер? — всё в паспорте.

## Структура паспорта 7Lamp

### Титульный лист

* Логотип 7Lamp
* Название изделия
* Артикул
* Год выпуска
* «ПАСПОРТ ИЗДЕЛИЯ»
* Внизу: адрес производителя, сайт

### 1. Общие сведения

Описание назначения изделия, краткая характеристика:

```
Настоящий паспорт распространяется на светильник светодиодный
настенный декоративный 7Lamp "Волна", артикул 7L-WAVE-600-W.

Светильник предназначен для декоративного освещения интерьеров
помещений (ресторан, офис, холл) при температуре от +5 до +40°C
и относительной влажности не более 80%.
```

### 3. Комплект поставки

Список всего, что в коробке:

1. Светильник в сборе — 1 шт
2. Монтажная пластина — 1 шт
3. Крепёжный набор (4 винта, 4 дюбеля) — 1 комплект
4. Кабельный ввод M20 — 1 шт
5. Паспорт — 1 шт
6. Инструкция по монтажу — 1 шт
7. Гарантийный талон — 1 шт

### 4. Устройство и принцип работы

Краткое описание конструкции с схемой:

```
Светильник состоит из:
- Корпуса из анодированного алюминия
- LED-модуля (Samsung LM301B, 20 шт)
- Драйвера (Mean Well HLG-40H-C700)
- Рассеивателя (поликарбонат матовый 2,5 мм)
- Монтажной пластины

Принцип работы: напряжение 220В поступает на драйвер,
который преобразует его в постоянный ток 700 мА для питания LED-модуля.
Световой поток проходит через рассеиватель и равномерно распределяется
в интерьере.
```

+ Схема «взорванной сборки» (exploded view) в этом разделе — не обязательно, но очень помогает сервису.

### 5. Требования безопасности

Стандартные правила безопасной эксплуатации:

```
- Установку и обслуживание производит квалифицированный персонал
- Перед монтажом и обслуживанием — обесточить линию питания
- Запрещена эксплуатация при повреждении корпуса, кабеля, разъёмов
- Не закрывать корпус теплоизолирующими материалами
- Запрещено использование во взрывоопасных помещениях
```

### 6. Инструкция по установке

Отсылка на отдельный документ (IKEA-style) + краткий пошаговый текст:

1. Выбрать место установки (высота 1500 мм от пола, на стене)
2. Разметить положение монтажной пластины
3. Просверлить отверстия диаметром 8 мм, глубиной 60 мм
4. Установить дюбели
5. Прикрутить монтажную пластину винтами
6. Подключить кабель питания к клеммнику
7. Надеть светильник на монтажную пластину
8. Зафиксировать винтом снизу
9. Подать напряжение и проверить работу

### 7. Техническое обслуживание

```
- Периодичность обслуживания: ежегодно
- Обесточить светильник перед обслуживанием
- Протереть корпус мягкой сухой тканью (при необходимости — слабый мыльный раствор)
- Проверить надёжность крепления
- При обнаружении дефектов — обратиться к производителю

Не использовать абразивные материалы, растворители, спирт.
```

### 8. Транспортирование и хранение

```
- Транспортирование: всеми видами закрытого транспорта
- Температура транспортирования: от -40 до +50°C
- Влажность: до 90%
- Хранение: в отапливаемых сухих помещениях
- Температура хранения: от +5 до +40°C
- Срок хранения: 3 года со дня изготовления
```

### 9. Гарантийные обязательства

```
Производитель гарантирует соответствие изделия техническим
требованиям при соблюдении условий эксплуатации, монтажа,
транспортирования и хранения.

Гарантийный срок: 3 года со дня продажи.

Гарантия не распространяется на случаи:
- Механических повреждений
- Нарушения правил эксплуатации
- Неправильного монтажа
- Воздействия воды при повреждённом уплотнении
- Попыток самостоятельного ремонта

Для гарантийного обслуживания обращаться по адресу:
```

## Форматирование и оформление

### Формат

* Бумага A4, книжная
* Шрифт основной — Arial / Helvetica, 10-11 пт
* Заголовки — 14 пт, жирные
* Таблицы — со стандартной сеткой 7Lamp
* Логотип в шапке каждой страницы

### Объём

* Типовой паспорт — 4-8 страниц
* Сложные изделия — до 15 страниц
* Простые — 2-3 страницы (+ краткая инструкция)

### Язык

* Русский — обязательно
* Английский — для экспорта (отдельный документ или билингва)

## Шаги заполнения

### Шаг 1. Собрать данные проекта

Из предыдущих этапов:

* Спецификация компонентов → для раздела «Устройство»
* Чертежи → для раздела «Габариты»
* Результаты испытаний → для раздела «Технические характеристики»
* Сертификат → для раздела «Сертификация»

### Шаг 2. Открыть шаблон

В папке проекта создать `6-pasport/` и скопировать туда шаблон.

### Шаг 3. Заполнить по разделам

Последовательно каждый раздел. Пропуск — сразу в чек-листе.

### Шаг 4. Использовать LLM для текстов

Разделы «Устройство», «Безопасность», «Обслуживание» — шаблонные. LLM пишет первый черновик, вы корректируете.

### Шаг 5. Вставить изображения

Внешний вид, exploded view, схема монтажа.

### Шаг 6. Проверка

* Все параметры сверены с фактическими
* Все разделы заполнены
* Орфография и пунктуация
* Соответствие ТР ТС

### Шаг 7. Подписи и печати

* Главный инженер
* ОТК
* Печать 7Lamp

## Типовые ошибки

| Ошибка | Последствия | Решение |
|--------|-------------|---------|
| Пропуск обязательных разделов | Возврат от ОТК / отказ сертификации | Чек-лист заполнения |
| Неправильные технические параметры | Рекламации, возвраты | Сверка с протоколом испытаний |
| Нет гарантийных обязательств | Проблемы с заказчиком | Обязательный раздел |
| Нет сведений об утилизации | Нарушение экологических требований | Стандартная формулировка |
| Нет ТР ТС | Проблемы на таможне | Обязательное указание |
| Старая форма | Не соответствует текущим стандартам | Используйте актуальный шаблон 7Lamp |
| Только PDF без оригинала Word | Не отредактируется на следующую партию | Хранить исходник .docx |
