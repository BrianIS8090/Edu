# Моделирование светильников в Rhino

Moi3D отлично справляется с быстрым моделированием простых корпусов, но рано или поздно задача выходит за его возможности. Параметрический радиатор с изменяемым количеством рёбер, сложная поверхность двойной кривизны, документация с размерами прямо в модели — здесь нужен Rhino. В этом уроке разберём, когда переключаться на Rhino, какие инструменты использовать и как организовать работу между двумя программами.

***

## Когда использовать Rhino, а когда Moi3D

Оба инструмента работают с NURBS-геометрией и читают одни и те же форматы. Разница — в сценариях использования.

| Критерий                | Moi3D                                 | Rhino                                     |
| ----------------------- | ------------------------------------- | ----------------------------------------- |
| Скорость освоения       | Минимальный порог входа, 2-3 дня      | Требует 2-3 недели практики               |
| Простые корпуса         | Идеален: быстрые булевы, экструзии    | Избыточен для простых задач               |
| Сложные поверхности     | Ограничен: нет точной правки CV-точек | Полный контроль NURBS-поверхностей        |
| Параметрика             | Отсутствует                           | Grasshopper — визуальное программирование |
| Документация            | Нет инструментов                      | Layouts, размеры, сечения                 |
| Скрипты и автоматизация | Нет                                   | Python, Grasshopper, RhinoScript          |
| Стоимость               | \~\$300                               | \~\$1000 + плагины                        |

**Правило для инженера 7Lamp:** начинайте моделирование в Moi3D. Переходите в Rhino, когда задача требует параметрики, сложных поверхностей или подготовки чертежей.

> Не пытайтесь делать всё в одной программе. Сила связки Moi3D + Rhino — в том, что каждый инструмент работает там, где он эффективнее.

***

## Базовые операции Rhino для светотехника

Rhino предлагает сотни команд, но для моделирования светильников достаточно освоить ключевой набор. Разделим их по задачам.

### Формообразование

* **ExtrudeCrv** — выдавливание кривой вдоль направления. Основной инструмент для линейных профилей и корпусов

* **Sweep1 / Sweep2** — протягивание профиля вдоль одной или двух направляющих. Используйте для корпусов с переменным сечением

* **Loft** — построение поверхности через несколько сечений. Незаменим для плафонов и рассеивателей сложной формы

* **Revolve** — вращение профиля вокруг оси. Даунлайты, рефлекторы, линзы — всё, что имеет ось симметрии

### Модификация

* **BooleanDifference / BooleanUnion / BooleanIntersection** — вырезание отверстий, объединение деталей, получение пересечения. Работают аналогично Moi3D

* **FilletEdge** — скругление рёбер с заданным радиусом. Указывайте радиус не менее 0.5 мм для фрезеровки

* **ChamferEdge** — снятие фаски. Применяйте на кромках, которые будут контактировать с руками монтажника

* **Shell** — создание оболочки из твёрдого тела. Задайте толщину стенки и укажите грани для удаления

### Анализ

* **ShowEdges** — поиск открытых рёбер (незамкнутых). Критично перед экспортом в STEP

* **CurvatureAnalysis** — проверка плавности поверхности. Помогает избежать «заломов» на видимых частях светильника

* **DraftAngleAnalysis** — проверка литьевых уклонов. Покажет, извлечётся ли деталь из формы

## Работа с кривыми и NURBS-поверхностями

**NURBS** (Non-Uniform Rational B-Splines) — математическое описание кривых и поверхностей, на котором построен Rhino. Понимание основ NURBS помогает строить чистую геометрию с первого раза.

### Контрольные точки

Каждая NURBS-кривая определяется **контрольными точками** (CV-точками). Перемещая их, вы меняете форму кривой. Команда `PointsOn` (F10) включает отображение CV-точек.

Практическое правило: чем меньше контрольных точек — тем плавнее кривая. Для профиля корпуса светильника обычно достаточно 6-10 точек.

### Степень кривой

**Степень** определяет плавность. Степень 3 (по умолчанию) подходит для большинства задач. Степень 1 даёт ломаную линию — используйте для технологических граней.

### Непрерывность стыков

Когда две поверхности соединяются, важна **непрерывность**:

* **G0** — поверхности касаются, но есть излом. Допустимо для невидимых стыков

* **G1** — касательная непрерывность. Стык плавный, но виден при определённом освещении

* **G2** — непрерывность кривизны. Стык неразличим. Обязателен для видимых поверхностей светильника

> Для корпусов светильников 7Lamp все видимые стыки поверхностей должны иметь непрерывность G2 или выше. Иначе на анодированном алюминии будут видны полосы.

## Grasshopper для параметрического моделирования

**Grasshopper** — визуальный редактор алгоритмов, встроенный в Rhino. Вместо ручного моделирования вы собираете схему из компонентов, а Grasshopper генерирует геометрию автоматически. Изменили один параметр — вся модель перестроилась.

### Когда нужен Grasshopper

* Типоразмерный ряд светильников (один алгоритм — десятки вариантов)

* Параметрические радиаторы с переменным числом рёбер

* Массивы отверстий с заданным шагом

* Генерация перфорации по заданному паттерну

* Автоматический экспорт всех типоразмеров в STEP

### Пример: параметрический радиатор

Задача — создать радиатор охлаждения для мощного COB-светильника. Количество рёбер и их высота зависят от тепловой мощности.

Алгоритм в Grasshopper:

1. **Входные параметры** — ширина основания (80 мм), длина (120 мм), количество рёбер (слайдер от 6 до 20), высота рёбер (слайдер от 15 до 40 мм), толщина ребра (2 мм)
2. **Генерация профиля** — компонент Rectangle создаёт основание, серия Line создаёт рёбра с равным шагом
3. **Экструзия** — компонент Extrude вытягивает профиль на заданную длину
4. **Скругления** — компонент Fillet добавляет радиусы у основания рёбер (обязательно для фрезеровки)
5. **Выход** — компонент Bake записывает результат в Rhino для экспорта

Двигая слайдер «количество рёбер» от 8 до 16, вы мгновенно получаете разные варианты радиатора. Тепловой расчёт показал, что нужно 12 рёбер высотой 25 мм — выставили значения и отправили в производство.

> Сохраняйте алгоритмы Grasshopper (.gh файлы) в папку проекта рядом с моделью. Через полгода не придётся вспоминать логику — откроете файл и измените параметры.

## Связка Rhino и Moi3D

На практике инженер 7Lamp работает в обеих программах. Важно правильно передавать модели между ними.

### Форматы обмена

| Формат          | Направление     | Особенности                                                                      |
| --------------- | --------------- | -------------------------------------------------------------------------------- |
| **3DM** (Rhino) | Rhino <-> Moi3D | Родной формат Rhino. Moi3D открывает 3DM напрямую. Лучший вариант для обмена     |
| **STEP** (.stp) | Rhino <-> Moi3D | Универсальный инженерный формат. Сохраняет точную геометрию. Теряет слои и цвета |
| **IGES** (.igs) | Устаревший      | Не рекомендуется. Часто приводит к щелям между поверхностями                     |

### Типичный рабочий процесс

1. Создайте базовый корпус в Moi3D (быстрее для простых форм)
2. Сохраните как 3DM
3. Откройте в Rhino для добавления сложных элементов (параметрический радиатор, сложные сопряжения)
4. Подготовьте чертежи в Rhino (Layouts)
5. Экспортируйте в STEP для производства

### Чего избегать при обмене

* Не конвертируйте NURBS в Mesh при передаче между программами — потеряете точность

* Не используйте IGES — формат устарел, создаёт щели между поверхностями

* Проверяйте единицы измерения при каждом импорте: Moi3D и Rhino могут быть настроены на разные единицы

## Организация модели

Порядок в модели экономит часы при доработке. Установите правила с первого файла.

### Слои

Создайте стандартную структуру слоёв для всех проектов светильников:

* **01\_Корпус** — основной корпус, профиль

* **02\_Заглушки** — торцевые элементы

* **03\_Оптика** — линзы, рефлекторы, рассеиватели

* **04\_Электрика** — плата, драйвер, клеммы

* **05\_Крепёж** — подвесы, клипсы, кронштейны

* **06\_Эскизы** — исходные кривые профилей (скрытый слой)

* **07\_Справочные** — габаритные контуры, оси, привязки

### Единицы измерения

Стандарт 7Lamp: **миллиметры**. Установите при создании файла: File -> Properties -> Units -> Millimeters. Допуск моделирования — 0.001 мм.

### Именование файлов

Формат: `[Код проекта]_[Название]_[Версия].3dm`

Пример: `P2024-031_Даунлайт-120_v03.3dm`

## Экспорт для производства

Финальный этап моделирования — передача файлов подрядчику. Каждый способ производства требует свой формат.

| Производство            | Формат      | Настройки экспорта                      |
| ----------------------- | ----------- | --------------------------------------- |
| **ЧПУ-фрезеровка**      | СDR (.cdr)  | CorelDraw v15                           |
| **3D-печать прототипа** | STL (.stl)  | Tolerance 0.01 мм, Angle 15°            |
| **Лазерная/гидрорезка** | DXF (.dxf)  | 2D-контуры, AutoCAD 2018, миллиметры    |
| **Литьё**               | STEP (.stp) | AP214, проверить уклоны перед экспортом |
| **Визуализация**        | OBJ / FBX   | С текстурными координатами, если нужно  |

### Чеклист перед экспортом

1. Запустите `ShowEdges` — убедитесь, что нет открытых рёбер (Naked Edges = 0)
2. Запустите `Check` — Rhino проверит целостность геометрии
3. Проверьте, что все детали — замкнутые твёрдые тела (Closed Solid Polysurface)
4. Убедитесь в правильности единиц измерения
5. Удалите вспомогательные кривые и точки (или скройте слои 06 и 07)
6. Экспортируйте только нужные детали через `SelLayer` -> `Export Selected`

## Типичные ошибки и как их избежать

### Незамкнутые поверхности

**Проблема:** модель выглядит целой, но при экспорте в STEP подрядчик получает «пустую» деталь. Причина — щели между поверхностями.

**Решение:** регулярно запускайте `ShowEdges` -> Naked Edges. Закрывайте щели командой `JoinEdge` (для щелей менее 0.01 мм) или перестройте проблемную поверхность.

### Отрицательные нормали

**Проблема:** часть поверхностей «вывернута наизнанку». При рендеринге появляются чёрные пятна, при 3D-печати — артефакты.

**Решение:** включите `Dir` для отображения нормалей. Все стрелки должны смотреть наружу. Команда `Flip` разворачивает нормаль выбранной поверхности.

### Слишком мелкие фаски и скругления

**Проблема:** радиус скругления 0.1 мм на ребре, которое будет фрезероваться. Фреза физически не может обработать такой радиус.

**Решение:** согласуйте минимальный радиус с подрядчиком. Для фрезеровки алюминия обычно не менее 0.5 мм (зависит от диаметра фрезы). Для литья — не менее 0.3 мм.

### Избыточная детализация

**Проблема:** в модели для ЧПУ присутствуют резьбы, надписи, насечки. Это утяжеляет файл и замедляет обработку CAM-программы.

**Решение:** резьбы указывайте на чертеже, а не в 3D-модели. Гравировку и маркировку — отдельным файлом DXF.

## Практика 7Lamp: пример рабочего процесса

Рассмотрим реальный сценарий. Поступил заказ на встраиваемый даунлайт диаметром 120 мм с параметрическим радиатором.

1. **Moi3D** — создали базовый корпус: цилиндр, вырезали посадочное место под LED-модуль, добавили пружинные клипсы. Время — 40 минут
2. **Rhino** — открыли 3DM-файл. Запустили Grasshopper-алгоритм для радиатора: задали диаметр 118 мм, 14 рёбер, высота 30 мм. Grasshopper сгенерировал радиатор за секунды
3. **Rhino** — объединили корпус и радиатор через BooleanUnion. Добавили скругления G2 на видимом кольце. Проверили через ShowEdges — 0 открытых рёбер
4. **Rhino** — экспортировали STEP для фрезеровки корпуса, DXF для лазерной резки монтажного кольца
5. **Rhino Layouts** — подготовили габаритный чертёж с основными размерами для согласования с заказчиком

Общее время — 2.5 часа вместо 4-5 часов полностью в одной программе.
