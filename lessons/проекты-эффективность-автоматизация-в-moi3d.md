# Автоматизация в Moi3D — скрипты, макросы, горячие клавиши

Moi3D выглядит как простой инструмент «для рисования», но под капотом у него полноценная система автоматизации: JavaScript-скрипты, кастомизируемые меню, настраиваемые горячие клавиши, плагины. Инженер, который владеет базовой автоматизацией, работает в 2-3 раза быстрее коллеги, кликающего по меню. В этом уроке — что можно автоматизировать в Moi3D, как написать первый скрипт и где взять готовые. Парный урок — [Шаблонизация рутины](lessons/проекты-эффективность-шаблонизация-рутины.md).

---

## Три уровня автоматизации

### Уровень 1. Горячие клавиши

Базовая автоматизация — каждая частая команда должна иметь сочетание клавиш. Это экономит 1-2 секунды на операцию, но за день складывается в 30-40 минут.

### Уровень 2. Пользовательские команды

Мини-скрипты, выполняющие серию команд. Пример: «снять фаски на всех внешних кромках и установить слой «готово»» — одна команда вместо десяти.

### Уровень 3. Полноценные скрипты

JavaScript-программы, которые могут: генерировать геометрию по параметрам, читать/писать файлы, интегрироваться с другими программами.

---

## Настройка горячих клавиш

Moi3D позволяет переназначить клавиши через файл настроек. Зайдите: `Options → Shortcut keys`.

### Рекомендуемые клавиши 7Lamp

| Клавиша | Команда |
|---------|---------|
| `E` | Extrude (выдавить) |
| `F` | Fillet (скругление) |
| `Shift+F` | Chamfer (фаска) |
| `T` | Trim (подрезать) |
| `J` | Join (объединить) |
| `S` | Split (разделить) |
| `Shift+B` | Boolean Union |
| `Shift+D` | Boolean Difference |
| `Shift+I` | Boolean Intersection |
| `L` | Layer panel |
| `G` | Group (в группу) |
| `Shift+G` | Ungroup |
| `Space` | Повторить последнюю команду |

Запомнили 10 часто используемых — и работа ускорилась вдвое.

## Моё первое custom-action (пользовательская команда)

### Пример: снять фаску C0,5 и перенести в слой «Готово»

В Moi3D внутренний скриптовый язык — JavaScript. Открываем меню `Options → Custom UI items`. Нажимаем `Add action`.

```javascript
// Имя действия: Fasca05-Gotovo
script: moi.commands.runCommand('chamfer', { distance: 0.5 });
moi.geometryDatabase.getObjects().getSelected().setLayer('Готово');
```

Привязываем к горячей клавише `Shift+Alt+F`. Теперь нажатие этой комбинации:

1. Запускает инструмент фаски с радиусом 0,5
2. После применения — переносит объект в слой «Готово»

### Другие полезные custom-actions

* **Экспорт выделения в STEP** — одна клавиша, файл сохраняется в папку проекта с именем детали
* **Импорт из общей библиотеки** — открывает нужную папку и показывает список
* **Построение сетки крепёжных отверстий** — по параметрам «шаг, количество» создаёт массив

## Скрипты генерации геометрии

### Пример: линейный светильник по параметрам

Скрипт `generate-line.js`:

```javascript
// Параметры
var length_mm = 1200;
var width_mm = 30;
var height_mm = 40;
var hole_step_mm = 300;

// Построение корпуса
var box = moi.command.addBox(0, 0, 0, length_mm, width_mm, height_mm);

// Построение отверстий
for (var x = 100; x < length_mm - 100; x += hole_step_mm) {
    moi.command.addCylinder(x, width_mm/2, height_mm, 2.5, 10); // отверстие
}

// Сохранение
moi.fileSystem.save('line-' + length_mm + '.3dm');
```

Запуск через меню → получается готовая модель. При изменении параметров — новая модель за секунду.

### Что можно автоматизировать

* **Типовые профильные светильники** — задаётся длина, генерируется модель
* **Массивы крепёжных отверстий** — шаг, количество
* **Батч-экспорт деталей** — одной командой экспортируем все объекты в STEP/DXF
* **Стандартизация** — проверяет, все ли слои соответствуют регламенту, переименовывает

## Плагины Moi3D

Для Moi3D существует несколько внешних плагинов:

### TriangulatorMoI

Оптимизация сетки перед экспортом в STL для 3D-печати. Уменьшает размер файла в 2-5 раз без потери геометрии.

### MoiScript Manager

Удобный менеджер JavaScript-скриптов — установка, запуск, организация.

### Moi3D Scripting API (официальное)

Документация API для разработки сложных скриптов. Содержит примеры работы с геометрией, файлами, интерфейсом.

## Excel-макросы для инженера

### Автоматизация спецификации

VBA-макрос в Excel, который:

1. Читает список компонентов
2. Запрашивает актуальные цены у подрядчиков (через API или вручную введенный прайс)
3. Считает общую стоимость с учётом скидок
4. Генерирует PDF-версию

**Экономия:** с 2 часов до 15 минут на спецификацию.

### Генерация заявок подрядчикам

Макрос читает спецификацию, группирует по подрядчикам, формирует:

* Отдельный Word-документ для каждого подрядчика
* Список чертежей для упаковки в архив
* Отправку по email (опционально)

## Python-скрипты для batch-задач

### Пример: переименование DXF

Часто проект генерирует десятки DXF, которые нужно переименовать по шаблону. Python-скрипт делает это за секунду:

```python
import os

folder = 'C:/Projects/Line-1200/dxf/'
project_prefix = 'LINE-1200-'

for file in os.listdir(folder):
    if file.endswith('.dxf'):
        new_name = project_prefix + file
        os.rename(os.path.join(folder, file), os.path.join(folder, new_name))
```

Таких скриптов в 7Lamp — десятки. Хранятся в общей библиотеке.

### Интеграция с ERP

Скрипт читает спецификацию из Excel, формирует структуру JSON, отправляет в API 7Lamp ERP. Автоматически появляется заявка в производство.

## Типовые ошибки

| Ошибка | Последствия | Решение |
|--------|-------------|---------|
| Не используют горячие клавиши | Работают медленно | Настроить топ-10 клавиш сразу |
| Пишут скрипт под 1 задачу | Потом не переиспользуется | Параметризовать, делать универсальным |
| Скрипты хранятся локально | Коллеги не могут использовать | В общую библиотеку |
| Без комментариев в скрипте | Через месяц сами не разбираетесь | Комментировать на русском |
| «Мне проще вручную» | Экономия копеек, потеря часов | Считать время до и после |
| Страх программирования | «Я инженер, не программист» | Базовые скрипты осваиваются за 5 часов |
